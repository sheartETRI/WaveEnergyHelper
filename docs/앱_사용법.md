# WaveEnergyHelper 현재 사용법

현재 실행 경로는 `main.py`이며 **차트 / 알람** 두 탭입니다. 이전 3탭 설명은 [보관된 사용법](archive/app_guide_v2.md)에 있습니다.

처음에는 선택한 차트 시간봉과 필요한 상위 게이트만 계산합니다. 전체 시간봉 레이더는 알람 탭을 열 때 실행되므로 첫 알람 조회에는 시간이 더 걸릴 수 있습니다. 탭을 바꿀 때 앱이 재실행되어 차트 확대 상태가 초기화될 수 있습니다.

## 실행

저장소 루트에서 PowerShell로 실행합니다.

```powershell
python -m pip install -r requirements.txt
$env:PYTHONUTF8 = "1"
python -m streamlit run main.py
```

개발용 설치와 검사는 [개발·검증](개발_검증.md)을 참고하세요.

## 사이드바

1. **데이터 새로고침**으로 OHLCV를 갱신합니다. 차트 확대·축소 상태는 초기화됩니다.
2. **심볼**에서 BTCUSDT·ETHUSDT·BNBUSDT·SOLUSDT를 고릅니다.
3. **타임프레임**은 1분봉부터 월봉까지 19개이며 기본은 1h입니다. 3h·2d·4d·2w는 원본 봉을 합성합니다.
4. 알람의 **이력 구간 (봉)**, **후보 신호 포함**, **스토캐 레이어**를 조절합니다.
5. 차트의 **스토캐 패널**, **MACD 패널**, **RSI 패널**, **차트 높이 (px)**를 조절합니다. 15m의 MACD 패널은 기본 꺼짐이며, 켜면 계산·알람·표시가 함께 활성화됩니다.
6. 수신 시각·마지막 봉 시각·데이터 주소·기동 코드 정보를 확인합니다. 저장본을 사용하면 오래된 데이터 안내가 표시됩니다.

## 차트 탭

캔들·거래량과 MA5·10·20·40·60·80·120·240을 표시합니다. 스토캐스틱은 대(20,10,10)·중(10,5,5)·소(5,3,3) 세 층이며 MACD·RSI를 별도 패널로 볼 수 있습니다.

가로 이동·확대, 가격축 세로 확대, 패널 경계 크기 조절, 특정 패널 집중 보기, 커서 봉 값 확인을 지원합니다. 패턴·MACD·구조 마커, 상위 시간봉 게이트 문맥, 후보 기준선이 표시됩니다. 60MA는 선택한 시간봉의 60개 봉 이동평균입니다.

## 알람 탭

화면 순서는 다음과 같습니다.

1. **TF 레이더**: 여러 시간봉의 레벨 이탈·재탈환 상태 요약.
2. **기준 TF 레이더**: 대파동 쌍바닥·쌍봉 이후 60MA 전환을 관찰할 시간봉.
3. **알람 패널**: 마지막 봉의 지표·신호와 최근 이력. 스토캐 패턴·RSI 진입·MACD 교차·스윕·합류를 표시합니다.
4. **60MA 상방 전환 추적**: 쌍바닥 후보의 20봉 관찰 창, 전환·소멸·이미 상방, 다이버전스와 기울기.
5. **60MA 하방 전환 추적**: 쌍봉 이후 같은 관찰 창의 하방 전환·소멸·이미 하방.
6. **추세 구조 추적**: HH/HL/LH/LL 연쇄와 유지·경고·훼손 상태.
7. **전체 복사용 텍스트**: 화면에 표시한 요약과 표를 복사합니다.

현재 봉은 진행 중일 수 있습니다. 패턴 확정과 실제 봉 마감은 다른 개념이며, MACD는 교차 다음 봉에서도 부호가 유지돼야 표시됩니다. 추적·구조 정보는 미검증 관측으로 표시합니다. 봉 시각과 푸시 차이는 [시간·캐시 계약](시간_캐시_계약.md)에 정리했습니다.

## CLI와 푸시

```powershell
python scripts/alarm_cli.py --tf 1h,2h,4h --out logs/alarm.md
python scripts/alarm_cli.py --sections "TF 레이더,기준 TF 레이더"
python scripts/push_alarms.py --help
```

CLI는 Streamlit AppTest를 사용해 화면과 같은 복사 텍스트를 추출합니다. 파일 저장은 PowerShell의 리다이렉션 대신 `--out`을 권장합니다. 실제 시세 수신과 로컬 캐시 갱신은 발생할 수 있습니다.

상주 Pushbullet 설정·중복 방지·일일 요약·상태 파일은 [운영 안내](운영_안내.md)를 참고하세요. 앱 자체는 자동 주기 갱신을 하지 않습니다.
