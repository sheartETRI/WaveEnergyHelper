# WaveEnergyHelper 현재 사용법

현재 실행 경로는 `main.py`이며 **차트 / 알람 / 추세·관찰** 세 탭입니다. 이전 상세 화면 설명은 [보관된 사용법](archive/app_guide_v2.md)에 있습니다.

처음에는 선택한 차트 시간봉과 필요한 상위 게이트만 계산합니다. 전체 시간봉 레이더는 알람 탭을 열거나 추세·관찰 탭에서 명시적으로 조회할 때 실행되므로 첫 조회에는 시간이 더 걸릴 수 있습니다. 추세·관찰 탭을 열기만 하면 저장 결과를 읽으며 선택 차트의 데이터 적재도 생략합니다. 탭을 바꿀 때 앱이 재실행되어 차트 확대 상태가 초기화될 수 있습니다.

## 실행

저장소 루트에서 PowerShell로 실행합니다.

```powershell
python -m pip install -r requirements.txt
$env:PYTHONUTF8 = "1"
python -m streamlit run main.py
```

개발용 설치와 검사는 [개발·검증](개발_검증.md)을 참고하세요.

## 사이드바

1. **데이터 새로고침**으로 OHLCV를 갱신합니다. 차트 확대·축소 상태는 초기화됩니다.
2. **심볼**에서 BTCUSDT·ETHUSDT·BNBUSDT·SOLUSDT를 고릅니다.
3. **타임프레임**은 1분봉부터 월봉까지 19개이며 기본은 1h입니다. 3h·2d·4d·2w는 원본 봉을 합성합니다.
4. 알람의 **이력 구간 (봉)**, **후보 신호 포함**, **스토캐 레이어**를 조절합니다.
5. 차트의 **스토캐 패널**, **MACD 패널**, **RSI 패널**, **차트 높이 (px)**를 조절합니다. 15m의 MACD 패널은 기본 꺼짐이며, 켜면 계산·알람·표시가 함께 활성화됩니다.
6. 수신 시각·마지막 봉 시각·데이터 주소·기동 코드 정보를 확인합니다. 저장본을 사용하면 오래된 데이터 안내가 표시됩니다.

## 차트 탭

캔들·거래량과 MA5·10·20·40·60·80·120·240을 표시합니다. 스토캐스틱은 대(20,10,10)·중(10,5,5)·소(5,3,3) 세 층이며 MACD·RSI를 별도 패널로 볼 수 있습니다.

가로 이동·확대, 가격축 세로 확대, 패널 경계 크기 조절, 특정 패널 집중 보기, 커서 봉 값 확인을 지원합니다. 패턴·MACD·구조 마커, 상위 시간봉 게이트 문맥, 후보 기준선이 표시됩니다. 60MA는 선택한 시간봉의 60개 봉 이동평균입니다.

차트 해석의 근거는 별도 **추세·관찰** 탭에서 확인합니다. 이 탭의 관찰·상위·하위 차트 열기 버튼을 누르면 해당 시간봉으로 맞춘 차트 탭으로 이동합니다. 사이드바의 시간봉은 열어 보는 차트만 바꾸며, 마지막 레이더가 선정한 관찰 대상과 이유를 바꾸지 않습니다.

## 알람 탭

화면 순서는 다음과 같습니다.

1. **TF 레이더**: 여러 시간봉의 레벨 이탈·재탈환 상태 요약.
2. **기준 TF 레이더**: 마감된 봉 기준의 전환 관찰 TF 요약과 표. 큰 추세와 선정 이유는 추세·관찰 탭에서 확인합니다.
3. **알람 패널**: 마지막 봉의 지표·신호와 최근 이력. 스토캐 패턴·RSI 진입·MACD 교차·스윕·합류를 표시합니다.
4. **60MA 상방 전환 추적**: 쌍바닥 후보의 20봉 관찰 창, 전환·소멸·이미 상방, 다이버전스와 기울기.
5. **60MA 하방 전환 추적**: 쌍봉 이후 같은 관찰 창의 하방 전환·소멸·이미 하방.
6. **추세 구조 추적**: HH/HL/LH/LL 연쇄와 유지·경고·훼손 상태.
7. **전체 복사용 텍스트**: 알람 요약·표와 같은 조회의 추세·관찰 설명을 함께 복사합니다. CLI도 이 통합 텍스트를 사용합니다.

알람 조회는 기존 기준 TF 계산과 종목별 저장을 갱신합니다. 큰 추세 패널·선정 설명·파동 에너지 설명은 본문에서 추세·관찰 탭으로 옮겼으며, 통합 내보내기에는 같은 조회의 설명을 계속 포함합니다.

## 추세·관찰 탭

**큰 추세 먼저 보기**, **레이더가 선정한 관찰 TF**의 설명, **파동 에너지 관찰**을 한곳에서 읽습니다. 처음에는 **관찰 TF 찾기**로 조회하고, 이미 조회했다면 **레이더 다시 조회**로 같은 탭에서 갱신합니다. 알람 탭에서 조회한 결과도 공유합니다. 탭을 열거나 차트 TF를 바꾸는 동작만으로는 다시 조회하지 않습니다. 선택한 차트의 적재가 실패해도 이 탭에서 기존 설명을 읽고 새로 조회할 수 있습니다.

관찰 설명은 기존 레이더 관찰 순서로 선정한 TF의 선정 이유·현재 판단·상위 환경·하위 진행·다음 확인·관찰 기간·자료 기준을 표시합니다. 차트 시간봉에 맞춰 설명 대상을 바꾸는 선택기는 없습니다. **관찰/상위/하위 차트 열기** 버튼으로 해당 차트로 이동합니다. 상하위는 기존 연결 규칙을 따르며, 레이더에 없는 TF는 임의로 다른 TF를 대입하지 않고 미적재로 표시합니다. 관찰 조건을 충족하는 TF가 없거나 자료가 부족하면 그 상태를 표시하고, 이전 관찰 카드를 제거합니다.

MA60 방향은 같은 TF의 종가와 60봉 전 종가를 비교한 1봉 변화입니다. 다음 확인에 표시하는 종가는 다음 봉의 MA60 방향을 확인할 비교값이며, 목표가나 가격 예측이 아닙니다. 기존 전환 추적기의 상태는 별도 창·유효성 규칙을 따릅니다. 상·하방 후보가 함께 있으면 양쪽을 표시하며, 이미 해당 방향인 후보도 진행 추세 관찰로 남깁니다.

다음 마감 후 추세·관찰 탭의 **레이더 다시 조회**를 누르면 OHLCV 캐시를 비우고 같은 탭에서 관찰 TF를 다시 조회합니다. 레이더 조회 결과가 갱신될 때 같은 세션의 이전 관찰과 비교해 후보·전환 상태·MA 방향·자료 상태 변화를 안내합니다. 차트 TF 변경 자체는 관찰 대상을 재선정하지 않습니다. 이 안내는 자동 주기 갱신이나 푸시 발송이 아닙니다. 현재 설명은 알람 탭의 전체 복사 텍스트와 CLI에도 포함됩니다.

추세·관찰 탭에 유지한 카드에는 **레이더 조회 기준 시각**을 표시합니다. 이 시각은 실제 수신 시각과 다릅니다. 저장된 다음 확인 시각이 지나면 선정 TF·이유는 유지하고 다음 조건·잔여 기간은 재조회 안내로 바꿉니다. 사이드바 새로고침으로 현재 차트만 갱신한 결과를 레이더 재조회 결과와 섞지 않습니다. 종목을 바꾸면 해당 종목의 조회 결과를 따로 표시합니다.

기준 TF 레이더와 설명 카드는 **마감봉 기준**입니다. 다른 기존 알람·추적 표에는 진행 중인 봉이 포함될 수 있습니다. 패턴 확정과 실제 봉 마감은 다른 개념이며, MACD는 교차 다음 봉에서도 부호가 유지돼야 표시됩니다. 추적·구조 정보는 미검증 관측으로 표시합니다. 봉 시각과 푸시 차이는 [시간·캐시 계약](시간_캐시_계약.md)에 정리했습니다.

### 큰 추세 먼저 보기

**주 기준은 4d MA10**, **전체 추세 교차 확인은 1d MA60**입니다. 방향은 각 TF에서 직전 마감봉 대비 MA의 1봉 변화로 측정합니다. 종가가 MA 위·아래에 있는지는 방향과 별도로 표시합니다.

| 두 추세 기준 | 낮은 TF의 방향 | 해석 |
|---|---|---|
| 모두 하락 | 상승 | 하락 추세 내 역추세 반등 관찰 |
| 모두 상승 | 하락 | 상승 추세 내 조정 관찰 |
| 모두 같은 방향 | 같은 방향 | 큰 추세와 동행 |
| 방향 충돌·평탄·자료 부족 | 어느 방향이든 | 큰 추세 해석 보류 |

현재 MA 방향과 전환 관찰 대상도 구분합니다. 예를 들어 상위 기준·현재 시간봉 MA60이 모두 하락 중이고 해당 시간봉에 쌍바닥이 나왔다면, 현재 방향은 큰 추세와 동행하지만 상방 전환 관찰은 역추세 반등 후보입니다. 시간봉 쌍바닥만으로 상위 추세가 바뀌었다고 보지 않습니다.

주봉처럼 기준보다 큰 TF, 또는 일봉 MA60처럼 4d MA10보다 긴 관측 범위는 하위 움직임으로 분류하지 않습니다. 높은 TF를 먼저 고려하는 것은 사용자의 해석 정책이며, 성공 확률이 항상 높다는 통계 판정은 아닙니다.

4d MA10은 명목상 40일 범위의 추세를 봅니다. 다만 4일 간격 종가 10개를 평균하므로 매일 종가 40개를 평균하는 일봉 MA40과 값·갱신 주기가 다릅니다. 두 추세 기준은 같은 조회 시점의 최신 마감값을 각각 사용하고 실제 마지막 마감 시각을 표시합니다. 4d가 일봉보다 몇 일 먼저 마감된 것은 정상입니다.

재확인 시각은 해당 관찰 TF와 두 추세 기준의 다음 마감 중 가장 빠른 시각입니다. 상위 기준 갱신 시각이 지나면 이전의 ‘반등·조정’ 해석을 현재 판단으로 계속 사용하지 않고 레이더 재조회를 안내합니다.

#### 상승 추세 안의 변곡 준비

4일봉 MA10의 방향이 여전히 상승이어도 다음 세 조건이 함께 나타나면 **변곡 준비**를 별도로 표시합니다.

- MA10이 직전 봉보다 계속 상승하지만, 이번 상승폭이 이전 상승폭보다 작습니다.
- 같은 마감봉에서 MA5가 MA10 아래에 있습니다.
- 같은 마감봉에서 MACD선이 시그널선 아래에 있습니다.

화면은 MA10의 이전·현재 기울기와 MA5·MA10, MACD선·시그널선의 현재 관계를 보여 줍니다. 두 데드크로스의 발생 시각과 몇 봉 전인지도 각각 표시하며, 서로 다른 봉에서 교차했어도 현재 두 하방 관계가 유지되면 함께 읽습니다. 이미 아래에 있는 상태를 이번 봉의 교차로 표시하지 않습니다. 확보한 이력에 교차 사건이 없으면 발생 시각은 미확인으로 남깁니다. MACD의 두 선은 스토캐스틱 K·D와 구분합니다.

이때 큰 추세의 MA10 방향은 계속 상승입니다. 시간봉 하락을 상승 추세 내 조정으로 읽더라도 **상위 기준에 변곡 준비 근거가 동반됨**을 함께 확인해야 합니다. MA10이 실제 하락으로 바뀌는 것은 다음 단계의 별도 관측이며, 준비 조건이 깨지면 준비 표시를 해제합니다.

최소 35개의 연속된 완성 4일봉이 필요하고 최초 부분봉은 MACD의 EMA 초기 계산에만 사용합니다. 미마감·자료 부족·누락·결측·갱신 지연이면 판정을 보류합니다. 차트 TF를 바꿔도 마지막 레이더 조회의 근거를 유지하고, 다음 추세 확인 시각이 지나면 레이더 재조회를 안내합니다. 기존 알람 목록의 ‘교차 다음 봉 유지’ 규칙과 달리, 이 설명은 같은 마감봉에서 확인한 현재 관계와 교차 사건을 별도로 표시하는 관찰입니다.

이는 하락 확정이나 매매 지시가 아닌 사용자 관찰 정책입니다. MACD·SMA의 공식 계산과 이 조합의 범위는 [파동에너지 공식 정리 §15](파동에너지_공식_정리.md#15-상승-추세-안의-변곡-준비-tp1-2026-10-29)에 기록했습니다.

### 파동 에너지 관찰

추세·관찰 탭의 **파동 에너지 관찰 — 대·소파동과 MA10**에서 같은 시간봉의 대·중·소파동 관계를 봅니다. 기존 레이더의 8개 TF에 4d를 더한 관측입니다. 60MA 전환 후보가 없어도 이 관측은 표시됩니다.

- **대파동 하락·소파동 쌍바닥 미확정:** 현재 하락 구간의 반전 근거를 기다립니다.
- **소파동 후보:** 두 번째 바닥 형성 중이며 기존 폭 조건 확정을 기다립니다.
- **소파동 확정:** 내부 반전 근거가 발생했습니다. 대파동 K의 방향 변화를 별도로 확인합니다.
- **대파동 방향 변화:** 소파동 확정이 선행했는지, 같은 봉인지, 확정 없이 바뀌었는지 구분합니다.
- **MA10 방향 불일치:** 대파동 방향과 실제 10MA 방향이 다릅니다. 기존 방향의 지속을 단정하지 않습니다.

상승 중에는 쌍봉을 기다리는 대칭 규칙을 사용합니다. ‘미확정’은 현재 대파동 방향 구간 안에서의 관측이며, 구간 시작을 확보하지 못하면 판단을 보류합니다. 대파동 K가 하락한다는 사실만으로 10MA 하락이나 향후 하락 지속을 뜻하지 않습니다.

관찰 순서는 소파동 확정·대파동 방향 변화, 소파동 후보, 선행 확정 없는 방향 변화, 소파동 대기 순이며 동률이면 큰 TF부터입니다. 이는 관찰 편의를 위한 순서입니다. 먼저 큰 추세를 확인하고, 표의 **추세 안의 해석**에서 각 TF의 MA10 상승·하락이 순행인지 역추세 반등·조정인지 읽습니다. 카드에는 다음 마감 시각·소파동 후보 확인선·다음 MA10 방향의 비교 종가가 표시됩니다. 추세·관찰 탭에서는 마지막 에너지 레이더 결과를 펼쳐 볼 수 있으며, 차트 TF 변경으로 관찰 대상이 바뀌지 않습니다.

4d는 기존 4일 차트와 같은 길이의 일봉 원본에서 연속된 4개 마감 일봉을 묶습니다. 부분봉은 제외하며, 카드에 실제 마감과 집계 기준을 표시합니다. 일봉 조회창 기준이 달라지면 기존 4일 차트의 봉 묶음도 달라질 수 있습니다. 자세한 범위는 [시간·캐시 계약](시간_캐시_계약.md)을 참고하세요.

## CLI와 푸시

```powershell
python scripts/alarm_cli.py --tf 1h,2h,4h --out logs/alarm.md
python scripts/alarm_cli.py --sections "TF 레이더,기준 TF 레이더"

```

CLI는 Streamlit AppTest를 사용해 화면과 같은 복사 텍스트를 추출합니다. 파일 저장은 PowerShell의 리다이렉션 대신 `--out`을 권장합니다. 실제 시세 수신과 로컬 캐시 갱신은 발생할 수 있습니다.

상주 Pushbullet 설정·중복 방지·일일 요약·상태 파일은 [운영 안내](운영_안내.md)를 참고하세요. 앱 자체는 자동 주기 갱신을 하지 않습니다.
