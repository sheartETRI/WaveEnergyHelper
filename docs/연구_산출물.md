# 연구 코드와 산출물 관리

## 코드 사용 경로

[모듈 색인](inventory/modules.csv)은 운영 정적 의존, 동적 상세 패널 등록, 직접 실행 경로, 참조하는 모듈을 기록합니다. 다음 명령으로 갱신합니다.

```powershell
python scripts/maintain_inventory.py
```

정적 도달 가능은 실제 모든 실행에서 호출된다는 뜻이 아닙니다. 함수 내부 import도 포함합니다. 문자열 기반 패널 등록은 별도 열로 표시합니다. 파일명 참조는 계산된 경로·외부 소비자를 모두 발견할 수 없으므로 사용처 미확인은 보존 대상으로 둡니다.

| 기능군 | 현재 사용 경로·보존 이유 |
|---|---|
| `tracking/` | 앱과 알림의 공용 계산 |
| `data/frames.py`, `utils/alarm_text.py` | 앱·구형 알림이 함께 사용하는 적재와 신호 문구 |
| `notify/legacy_signals.py` | `--legacy-signals` 전용 구현. `scripts/push_alarms.py`에서 기존 함수 이름 재노출 |
| `display/detail_tab`, `panel_registry`, `journal_tab`, `v2_campaign_view` | 이전 UI 조립 코드. 현재 기본 화면 미연결, 연구 패널 검증에서 사용 |
| `narration/` | 이전 상세 패널의 선택 해설. 현재 앱에서 API 호출 없음 |
| `charts/plotly_builder.py` | 이전 차트의 재현·비교 검사 |
| `analysis/wave_*` | 운영 게이트의 간접 의존과 연구 라이브러리가 함께 있음. 모듈별 색인으로 구분 |
| `validation/wave_ma60_turn_probe.py` | 해시 고정 계측 원본과 연구 실행. 운영은 순수 함수를 추출한 `tracking/signals.py` 사용 |
| `validation/*_sweep.py` 등 | 당시 연구 실행·보고서 생성. 실행 전 입력 경로·기간·옵션 확인 |

연구 패키지는 `python -m pip install -r requirements-research.txt`로 설치하고 `python -m pytest -m "research and not network"`로 오프라인 재현 검사를 수행합니다. 수동 연구 스크립트는 `python validation/<파일>.py` 형식이며, 기존 결과를 덮어쓸 수 있으므로 별도 작업 복사본에서 해당 스펙·입력 기간을 먼저 확인합니다.

현재 미연결 UI와 분석 모듈의 대규모 이동은 하지 않습니다. 고정 코드·동적 import·CSV 경로의 소비자가 남아 있어 기존 경로를 유지하고 색인으로 구분하는 방식을 채택했습니다. 운영에 필요한 계산만 실제로 분리했습니다.

## 자료 보관 정책

[자료 색인](inventory/artifacts.csv)은 보고서·그림·CSV·JSON의 코드·문서 참조와 생성 후보를 기록합니다. `producer_candidates`는 파일명 문자열을 참조하는 실행 스크립트 후보로, 실제 생성기 확정을 뜻하지 않습니다. `experiment_sources`는 같은 이름의 연구 보고서 후보이며 기간·파라미터는 해당 원문에서 확인합니다. 실험 조건을 확인하지 못한 결과는 명시적으로 보존합니다.

| 구분 | 위치 | 정책 |
|---|---|---|
| 고정 원문·검증 기준 데이터 | 기존 docs·tests·validation | Git 보관, 출처와 해시 유지 |
| 기존 연구 결과·그림 | 기존 validation·docs | 소비 경로와 보고서 링크 유지; 자동 삭제 없음 |
| 누적 journal·ledger | 기존 실행 경로 | 재생성 캐시로 취급하지 않음, 백업 후 복원 |
| 재수신 가능한 OHLCV | `data/cache/` | Git 제외, 테스트는 임시 경로 |
| 앞으로 생성하는 정리 검증·로그 | `artifacts/` | Git 제외, 실행 날짜·명령과 함께 보관 |
| 코드·자료 색인 | `docs/inventory/` | 재생성 가능하지만 검토를 위해 Git 보관 |

기존 자료의 경로 변경을 하지 않으므로 분석 CSV 소비자·과거 이미지 링크를 변경할 필요가 없습니다. 새 산출물만 `artifacts/`로 모읍니다. 과거 결과의 실험 조건이 불명확한 경우 색인에서 상태를 유지하고 해당 보고서·Git 이력으로 확인합니다.
