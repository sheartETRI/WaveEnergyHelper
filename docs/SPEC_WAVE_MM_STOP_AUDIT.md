# SPEC_WAVE_MM_STOP_AUDIT — 자금 관리 1라운드: 손절 규칙 감사 (frozen)

작성: 2026-09-04. §8 사용자 확인 완료로 동결. 실행 중 판정 기준·체결 가정·
모집단을 수정하지 않는다.

## 0. 연구 축 이동의 근거와 위치

- ALIGN_GATE 확인 검정의 진단: F2-b 게이트 수익은 "가끔 크게 낫다"형 양의 왜도 —
  에피소드 과반이 무게이트 열세, 통합 양수는 소수 에피소드가 견인.
- 이 프로파일의 성패는 진입이 아니라 노출·손실 규칙이 좌우한다: 평범한 다수
  에피소드를 얼마나 싸게 버티고, 소수의 큰 에피소드에 얼마나 실려 있는가.
- 사용자 현행 규칙 (기준선, 이하 BASE — §8 확인 완료):
  자본 7,000만원 / 트랜치당 5% 이하 분할진입(재량 하이브리드: 하락 추가·상승
  추가 모두 허용, 고정 기준 없음) / 평균 매수단가 대비 −3% 손절 / 동시 1포지션 /
  신호 건너뜀 조건 없음 / 별도 청산 규칙 없음 (본 스펙 기본값 20봉 시간 청산 채택).
  트랜치당 자본 위험 ≈ 0.15% + 비용 — 파산 위험은 사실상 논점이 아니며,
  본 축의 질문은 기회비용이다.
- 정직성 조항: 자금 관리는 엣지를 만들지 못한다. 분포의 형태(성장률·드로다운·
  노출)를 바꿀 뿐이다. 진입 엣지의 상한은 이전 라운드들이 측정한 그대로다.

## 1. 라운드 구성

- MM-R0 (판정 없음): 트레이드 시뮬레이터 구축·검증 + BASE 특성 계측
- MM-R1 (판정 1개): 손절 규칙 감사 — BASE의 −3% 고정 손절 vs 무손절(시간 청산 단독)

## 2. 시뮬레이터 고정 정의 (MM-R0)

- 모집단: 2021-01-01 ~ 2026-09-01, {BTC, ETH, BNB}, F2-b 게이트 통과 이벤트
  (승격된 워치리스트 필터와 동일 — 도구의 실사용 흐름을 모사)
- 체결 모형:
  - 진입: 이벤트 봉 다음 봉 시가
  - 손절: 봉 내 low ≤ 기준가×0.97 → 기준가×0.97 체결, 슬리피지 0.05% 가산 (고정).
    기준가 = 평균 매수단가 (§8-2). 단일 진입 가정에서는 진입가와 동일하다.
  - 시간 청산: 진입 후 20 LTF봉 종가 (expectancy_20 지평과 정합)
  - 손절·시간 청산 동시 충족 봉은 손절 우선 (보수적)
  - 비용: 왕복 0.2% (고정, ALIGN_GATE 보조 보고와 동일 가정)
- 포트폴리오 제약: 동시 1포지션 (보유 중 발생 이벤트는 건너뜀 — BASE 그대로).
  심볼 간 동시 신호는 이벤트 시각 순, 동시각이면 심볼 사전순 (자의성 고정)
- 사이징: 트랜치 1회 5% 고정. **분할진입은 이번 라운드에서 모델링하지 않는다**
  — §8-1 확인 결과 실규칙이 고정 기준 없는 재량 하이브리드(물타기·불타기 병용)
  이므로, 기계적 분할 규칙을 넣는 순간 실규칙 검증이 아니라 규칙 발명이 된다.
  단일 진입 가정임을 한계에 명기한다. 분할 라운드는 별도 스펙으로 다루되,
  검증 대상은 재량의 재현이 아니라 "재량 하이브리드를 대체할 후보 고정 규칙들"
  이 된다.
- 검증 (판정 전 필수 통과):
  - 무손절·무비용·항상체결 설정에서 시뮬레이터 트레이드 수익 ≈ 저널
    expectancy_20 재현 (허용 오차 명시)
  - 손절 체결의 봉 내 순서 가정(low 우선) 단위 테스트
  - 1포지션 건너뜀 로직: 보유 구간과 겹치는 이벤트가 정확히 제외되는지

## 3. MM-R0 계측 항목 (판정 없음, 이후 라운드의 기저율)

- 실제 체결 트레이드 수 (1포지션 제약 후 — 이벤트 수 대비 축소율)
- BASE의: 손절 발동률, 트레이드당 순기대값(비용 차감), 월별 수익 계열,
  최대 드로다운, 노출률(포지션 보유 시간 비율)
- 손절된 트레이드의 반사실 추적: 손절 없었다면 20봉 시점 수익이 양수였을 비율
  (왼꼬리 절단 vs 승자 조기 청산의 직접 계측)

## 4. MM-R1 판정

- 주 비교 (단 하나): Δ = G(BASE) − G(NOSTOP)
  - G = 트레이드 계열의 로그 성장률 합 (기하 성과, 비용 차감 후)
  - NOSTOP = BASE에서 손절만 제거 (시간 청산 단독), 그 외 전부 동일
- 성공 기준 (전부 충족 시에만 "손절 유지" 판정):
  1. Δ > 0, 월 클러스터 부트스트랩 95% CI가 0 배제 (시드 기재)
  2. 체결 트레이드 수 ≥ 100 (양쪽 각각 — 미달 시 판정 불가로 기록하고 종료)
  3. 시계열 전/후 half-split 양쪽에서 Δ > 0
  4. 1h 스트림과 6h 스트림에서 Δ 같은 부호
- Δ < 0으로 기준 통과 시 "손절 해로움" 판정. 어느 쪽도 아니면 "식별 불가".
- 판정 결과는 규칙 권고이지 자동 적용이 아니다. 실운용 반영은 사용자 결정.

## 5. 보조 보고 (판정 미사용)

- 손절 폭 참고 곡선: {2%, 3%, 4%, 5%, ATR 배수 1개} 각각의 G — **탐색 표시,
  차기 스펙의 가설 재료일 뿐 이번 판정·권고에 사용 금지**
- 드로다운·노출률·손절 발동률의 BASE vs NOSTOP 비교
- 연도별 Δ (게이트 개방 편중과의 교차 확인)

## 6. 정지점

- 금지: 손절 폭·사이징·트랜치 수 스윕을 판정에 사용, 체결 가정 변경,
  분할진입 기준 발명, 진입 이벤트 정의 변경.

  이동하되, 본 라운드가 확정한 손절 규칙을 전제로 설계한다.

## 7. 한계 필수 기재

- 단일 진입 가정 (실제는 재량 하이브리드 분할 — 특히 평단 기준 손절은 물타기와
  결합 시 최초 진입가 대비 실질 손절 폭이 −3%보다 깊어지고 위험 자본이 트랜치
