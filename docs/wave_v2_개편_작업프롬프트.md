## 0. 개편의 본질 (반드시 이해하고 시작할 것)

기존 v1은 **"사용자가 TF를 선택 → 그 TF를 분석"** 구조다 (TF가 입력, 패턴이 출력).
v2는 이를 뒤집는다: **"전체 TF 사다리를 상시 스캔 → 쌍바닥/쌍봉이 확정된 TF를 발견 → 그 TF를 기준 TF로 승격 → 캠페인 실행"** (패턴이 입력, TF가 출력).

매수/매도의 최초 판단 시점 = 패턴 확정 TF의 발견 시점이다.
- 쌍바닥 확정 → 그 TF 위로 엘리어트 3파 기대 → **매수 캠페인**
- 쌍봉 확정 → 아래로 3파 기대 → **매도(청산/관망) 캠페인** (완전 대칭)

기존 25라운드 검증의 결론(단독 TF 규칙 hit 채점 = baseline +0.27%, residual 96%)을 전제로 한다. v2의 가설은 "채점 단위를 hit → **캠페인**(진입–청산–재진입 시퀀스)으로 바꾸고, 기준 TF를 패턴 주도로 승격하면 엣지가 나타난다"이다. 이 가설 자체가 검증 대상이며, 아래 §8의 종료 게이트를 따른다.

### 재사용 자산 (재작성 금지 — 소비만 한다)
- 검출기: 스토캐스틱/이평선 쌍바닥·쌍봉 + kind(HL/LL/HH/LH) + 넥라인 확정, 쓰리바닥/쓰리봉
- `dynamics_rules.py`의 RULE_TABLE 선언 패턴 (규칙 = 데이터)
- `data/binance.py` 수집·페이지네이션, `data/processor.py` 리샘플링
- `indicators/oscillators.py` MACD, `indicators/stochastic.py` 3층 스토캐
- forward journal / watchlist 채점 인프라 (`analysis/wave_live_forward_journal.py` 등)
- [F4] 도달 범위 공식, CORE_MA_PERIODS 체계

### 갈아엎을 대상
- `main.py`의 45패널 직접 조립 → 패널 레지스트리 + v2 종합 뷰
- 단독 TF 분석 전제의 UI 흐름

## 1. TF 사다리 정의

```
TF_POOL = ["15m", "30m", "1h", "2h", "4h", "6h", "8h", "1d", "4d", "2w"]
# 고정 사다리 아님 — 풀 + 비율 기반 동적 인접
```

- 30m/2h/6h/8h는 바이낸스 네이티브 인터벌. 4d는 1d에서, 2w는 1d(또는 1w)에서 리샘플링 (`resample_timeframe` + `CUSTOM_INTERVALS` 확장).
- **인접 정의 (확정): 비율 규칙, 예외 없음.**
  - `upper(tf)` = 풀에서 비율이 **×3.5~×6** 범위에 드는 TF. 복수면 **×4 최근접 우선**.
  - `lower(tf)` = ÷3.5~÷6 대칭, ÷4 최근접 우선.
  - 상·하위는 각각 독립 계산 — 대칭 보장 안 함 (예: upper(4h)=1d 이지만 lower(1d)=6h). 이것은 버그가 아니라 규칙의 결과다.
- 도출되는 인접표 (구현 시 단위 테스트로 고정할 것):

| TF | lower | upper | 비고 |
|---|---|---|---|
| 15m | — | 1h (×4) | 하위 없음 → 파동 카운팅 "불가" 표시 |
| 30m | — | 2h (×4) | 하위 없음 |
| 1h | 15m (÷4) | 4h (×4) | 6h(×6)보다 4h 우선 |
| 2h | 30m (÷4) | 8h (×4) | |
| 4h | 1h (÷4) | 1d (×6) | |
| 6h | 1h (÷6) | 1d (×4) | |
| 8h | 2h (÷4) | — | 1d는 ×3 → 범위 밖. **상위 없음** |
| 1d | 6h (÷4) | 4d (×4) | 4h(÷6)보다 6h 우선 |
| 4d | 1d (÷4) | 2w (×3.5) | 3.5 하한 포함으로 예외 불요 |
| 2w | 4d (÷3.5) | — | 상위 없음 |

- 상·하위가 없는 TF는 해당 역할 패널 비활성 (대체 TF를 임의로 끌어오지 않는다).
- **패턴 스캔(기준 TF 승격) 대상 = 풀 10개 전부 (확정).** 스캔 TF 증가로 동시 확정 충돌 빈도가 늘어난다 — L2의 상위 우선 규칙이 비율 순서(분 단위 크기 순)로 적용되며, suppressed 이벤트 저널 기록은 동일하게 유지.
- 데이터 충분성: 2w는 MA240 계산에 240×2주 ≈ 9.2년 필요 → 확보 불가 시 해당 TF는 CORE_MA 부분집합(예: MA5~60)만으로 동작하고 UI에 명시. 4d도 동일 점검.

## 2. L1 — 패턴 스캐너

전 TF 풀(10개) × 심볼(초기: BTCUSDT, ETHUSDT, BNBUSDT, SOLUSDT)에서 봉 마감마다 검출:

| 검출 대상 | 소스 | 비고 |
|---|---|---|
| 이평선 쌍바닥/쌍봉 (MA5, MA10 중심) | 기존 이평선 피봇 검출기 | kind + 넥라인 확정 필수 |
| 이평선 쓰리바닥/쓰리봉 | 기존 | MA5 쓰리바닥 = 강화 신호 |
| 스토캐 3층 쌍바닥/쌍봉 | 기존 | S5 조정 깊이 판정용 |

출력: `PatternEvent(symbol, tf, kind_pattern, ma_or_layer, direction, confirmed_bar, neckline_price)`
확정 의미론은 v1과 동일: **kind 일치 + 넥라인 돌파 = 확정** ([F7-a] 운영 정의). candidate는 스캐너에 표시하되 승격 불가.

## 3. L2 — 기준 TF 승격

- 패턴 확정 이벤트 발생 → 해당 TF가 **기준 TF**, 패턴 방향이 캠페인 방향.
- **동시 확정 충돌 규칙 (확정)**: 복수 TF에서 같은 심볼에 동시 확정 시 **상위 TF 우선** ([F1] 힘의 위계). 하위 TF 이벤트는 기각하지 않고 저널에 "suppressed_by_upper"로 기록만 한다 (사후 분석용).
- 반대 방향 캠페인 충돌(진행 중 매수 캠페인 중 상위 TF 쌍봉 확정 등): 상위 TF 우선 원칙에 따라 기존 캠페인을 CONFLICT 상태로 마킹하고 알림. 자동 청산은 하지 않는다 (현물 전략, 판단은 사용자).

## 4. L3 — 삼각 분석 (역할 확정)

| TF | 역할 (확정) | 구현 |
|---|---|---|
| 상위 1단계 | **참고 표시만** — 진입 판정에 사용하지 않음 | 상위 TF 레짐(MA120 vs 240)·배열·진행 중 패턴을 카드에 표시. 정합 여부를 저널 컬럼 `upper_alignment`로 기록 (관측 전용 — 사후에 게이트 승격 가치 측정) |
| 기준 TF | 캠페인 상태 기계 실행 (§5) | 진입·청산 판정은 기준 TF 단독 |
| 하위 1단계 | **3파 진행 확인 (파동 카운팅)** | [F5-e]: 기준 TF 쌍바닥 → 하위 파동이 3파로 전개. 하위 TF 스토캐 파동의 피봇 시퀀스로 1파/2파/3파 라벨링, 카드에 현재 파동 위치 표시 |

파동 카운팅 초기 구현(관측 전용, 보수적으로):
- 캠페인 시작 후 하위 TF 대파동(20,10,10)의 피봇을 추적: 첫 상승 스윙=1파 후보, 첫 조정 스윙=2파 후보, 재상승=3파 후보.
- 카운팅은 **표시·저널 기록만** 하고 상태 기계 전이에는 사용하지 않는다 (전이는 §5의 MACD·패턴 트리거만). 카운팅과 상태 기계의 일치율을 저널로 측정한 뒤 승격 여부 판단.

## 5. 기법 1 — 캠페인 상태 기계 (확정 사양)

현물 보유 전략. 모든 크로스는 **MACD선-시그널선** 기준 (스토캐 K/D 아님).

```
S0 SETUP    : 기준 TF에서 이평선 쌍바닥 확정 (kind HL + 넥라인 상향 돌파)
              MA10 쌍바닥 = 대파동 급 / MA5 쓰리바닥 동반 = 강화 플래그
S1 CONFIRM  : 기준 TF MACD 골든크로스 대기 (S0 이후 발생분만 유효)
S2 ENTRY-1  : 매수 시그널 발행 (가격·봉 기록)
S3 WAVE-1   : 보유 — 기준 TF MACD 데드크로스 발생 시 전이
S4 EXIT-1   : 전량 매도 시그널 (2파 조정 회피)
S5 WAVE-2   : 조정 깊이 예측 — 조정을 주도하는 기준 TF 스토캐 쌍봉의 급으로 결정
              소파동 쌍봉 → MA10~20 (최소 MA10 도달) / 중파동 → MA20~60 / 대파동 → MA60~120
              쌍봉 미확정 상태에서는 구간 "미정" 표시. 피보나치 38.2/50/61.8은 참고 오버레이만.
S6 ENTRY-2  : (예측 MA 구간 도달) AND (MACD 재골든크로스) → 재매수 시그널
              ★ 무효화 없음 — 구간 하단 이탈·저점 이탈·시간 경과 모두 취소 사유 아님. 무기한 대기.
S7 WAVE-3   : 보유 — 기준 TF에서 [대파동 스토캐 쌍봉] 또는 [MA10 쌍봉] 확정 시 청산 시그널 → 캠페인 종료
```

매도(쌍봉 발견) 캠페인은 위의 완전 대칭 (HL↔LH, GC↔DC, 매수↔매도). 현물 전제이므로 매도 캠페인의 실체는 "보유분 청산 + 재매수 금지 구간 표시"다.

주의 구현 사항:
- S6의 AND는 순서 무관 (구간 도달 후 GC, GC 후 구간 재도달 모두 유효). 단 GC는 S4 이후 발생분만.
- 상태 전이는 봉 마감 확정값으로만 판정 (인트라바 no). v1의 as-of 규율 유지.
- 무효화 없음의 리스크 계측: 저널에 재진입 트레이드의 **MAE(최대 역행폭)** 와 `entry2_after_low_break` (쌍바닥 저점 이탈 후 재진입 여부) 컬럼 필수. 이 데이터가 향후 "저점 이탈 시 보류" 필터의 승격 근거가 된다.

## 7. 캠페인 채점 + Forward Journal 확장

채점 단위 = 캠페인 (hit 아님). 캠페인당 두 트레이드:
- T1: ENTRY-1 → EXIT-1 수익률
- T2: ENTRY-2 → S7 청산 수익률
- 캠페인 합산 수익 = (1+T1)(1+T2)−1, 왕복 수수료 4회 차감(회당 0.1% 가정, 설정값)

저널 필수 컬럼: symbol, base_tf, direction, s0_pattern(급·kind·강화플래그), 각 상태 진입 시각/가격, T1/T2/합산, MAE(T2), entry2_after_low_break, upper_alignment, lower_wave_count_at_entry2, suppressed_by_upper 여부.

**전 구간 관측 전용으로 시작한다.** 시그널 카드는 발행하되 "관측 등급" 라벨. 승격은 §8 게이트 통과 후.

## 8. 검증 게이트 (사전 확정 — 변경 금지)

v1의 교훈: 종료 기준 없는 반복은 매몰비용만 키운다. 아래를 사전에 박는다.

- **G1 (엔진 정합)**: 과거 데이터 리플레이에서 상태 전이가 수동 차트 판독과 일치 (김박사 승인 케이스 10건 이상, ETHKRW 4h 사례 포함)
- **G2 (백테스트)**: 4심볼 × {1h, 4h, 1d} 과거 캠페인 전수 채점. **합산 기대값(수수료 차감 후) ≥ +0.5%/캠페인 AND 캠페인 n ≥ 100** → 통과 시 15m·4d·2w 확대 및 forward 관측 지속. 미달 시 → "기준 TF 승격 + 캠페인 구조" 가설도 기각으로 확정하고 트레이딩 용도 종료 (인프라는 보존)
- **G3 (forward)**: G2 통과 후 forward journal 60일 누적, 백테스트 대비 기대값 감쇠 50% 이내 → "추천 등급" 승격

## 9. 구현 순서 (커밋 단위)

1. TF 사다리 + 4d/2w 리샘플링 + 데이터 충분성 점검 (테스트 포함)
2. L1 스캐너: 기존 검출기를 전 TF 루프로 래핑, PatternEvent 스트림
3. L2 승격 + 동시 확정 충돌 규칙 (단위 테스트: 동시 확정 시나리오)
4. 기법 1 상태 기계 (전이 규칙 = 데이터 테이블 선언, 리플레이 테스트)
5. 캠페인 채점기 + 저널 스키마 확장
6. G1 리플레이 검증 → 김박사 승인
7. G2 백테스트 실행 → 리포트 (REPORT_V2_CAMPAIGN.md)
8. 시그널 카드 UI + 패널 레지스트리 재조립 (G2 통과 시)
9. 하위 TF 파동 카운팅 (관측 전용) — 8과 병행 가능

각 단계는 v1 규율 유지: 검출기 무수정 소비, 규칙은 데이터 선언, 관측 전용 → 게이트 승격, as-of 봉 마감 판정, 테스트 동반 커밋.

## 10. 미결 사항 (구현 중 김박사 에스컬레이션)

- 기법 2, 3 추가 시 판정표 병합 방식
