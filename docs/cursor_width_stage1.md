# 패치 지시: [F7-c/d] 너비 규칙 1단계 — 관측 전용 (+ 주석 정리)

## 배경

[F7-a] 깔끔함은 검토자 차트 판정으로 운영 정의가 확정됐다: **kind 일치 + 넥라인 돌파 확정** — 즉 현행 엔진이 이미 충실히 구현 중이며 추가 강화 불필요. 이번 라운드는 다음 품질 필터인 너비 규칙의 1단계다.

너비 규칙 요지 (검토자 이론):
- [F7-c] 직전 외바닥(단독 침체 진입)의 파동 너비가 현재 쌍바닥의 너비보다 작으면, 그 외바닥을 패턴의 1번 바닥으로 세지 않는다 — 현재 위치가 사실상 1번 바닥
- [F7-d] 너비가 부족한 쓰리봉, 또는 3번째 봉우리가 과매수에 재진입하는 쓰리봉 → 마지막 파동이 한 번 더 나올 수 있다 (트랩 경고)

이번 라운드는 **관측 전용** — 검출기·엔진 무수정. 너비는 K 시리즈에서 사후 계산 가능하므로 메타데이터 기록조차 불필요하다. `validation/` 확장만.

## 작업 2: 너비 관측 — `validation/width_obs.py`

ETHUSDT 4h (페이지네이션 1,600봉), 스토캐스틱 3레이어 대상:

### 기초 단위: 침체/과열 체류 구간
- K < oversold(20) 연속 구간 = 침체 체류(excursion), K > 80 = 과열 체류. 각 구간의 (진입 봉, 탈출 봉, 너비=봉 수, 최저/최고 K) 열거 — K 시리즈에서 직접 계산 (검출기 무관)

### [F7-c] 관측
1. 각 확정 쌍바닥(db, 3레이어)에 대해: 패턴 너비 = 1번 바닥 피봇(first_pos)~확정 봉 구간, 그리고 1번 바닥이 속한 침체 체류의 너비 W1, 2번 바닥 체류 너비 W2
2. **직전 외바닥**: 패턴 1번 바닥 직전의 독립 침체 체류(패턴에 속하지 않는 것)의 너비 W0 (없으면 해당 없음)
3. F7-c 위반 후보 집계: W0 < 패턴 너비인 사례 수/비율 — "직전 외바닥을 1번 바닥으로 세지 말았어야" 했던 패턴이 현 검출에서 얼마나 되나
4. 기존 hit 영향: 엔진 HIT·스윕 WOULD_HIT의 구성 db/dt 원자 중 F7-c 위반 후보에 해당하는 것 — 특히 Z2 F6-5c-b의 대파동 쌍바닥(W1=2/6 체류) 해당 여부 명시
5. 쌍봉은 과열 체류로 대칭 계산

### [F7-d] 관측
1. 각 확정 쓰리바닥/쓰리봉(tb/tt)에 대해: 세 체류의 너비 (W1, W2, W3)와 W3의 상대 크기, 3번째 극점의 침체/과열 재진입 여부
2. F7-d 경고 후보 집계: W3가 W1·W2 대비 현저히 작은 사례(비율 분포로 보고 — 임계 제안 금지), 3번째 재진입 사례 수
3. 해당 tb/tt가 ④⑤ hit의 원자로 쓰인 사례가 있으면 명시
