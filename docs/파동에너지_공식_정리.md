# 파동에너지 이론 — 이평선·스토캐스틱 공식 체계 정리

출처: 김우진, 「파동에너지 이론」 (개인 학습·구현용 정리 노트. 원문 표현이 아닌 규칙의 재구성이며 재배포 금지)

## 0. 표기

- MA{n} = n기간 단순이동평균. 책의 체계는 **5-10-20-60-120-240** (앱의 40, 80은 책에 없음 — §9 참고)
- 파동 = 슬로우 스토캐스틱: 소파동(5,3,3) / 중파동·본파동(10,5,5) / 대파동(20,10,10)
- HL/LL = 저점 높아지는/낮아지는, HH/LH = 고점 높아지는/낮아지는
- GC/DC = 골든크로스/데드크로스, "→" = 인과(원인 → 결과)

## 1. 힘의 위계 공식 (서열)

```
[F1-a] 이평선 힘:      MA5 < MA10 < MA20 < MA60 < MA120 < MA240
[F1-b] 파동 힘:        소파동 < 중파동 < 대파동
[F1-c] 통합 위계:      소파동 < 캔들 < 중파동 < MA5 < 대파동 < MA10
[F1-d] 쌍바닥 힘:      소파동 쌍바닥 < 캔들 쌍바닥 < 중파동 쌍바닥 < MA5 쌍바닥
```

대원칙: **추세는 이평선에서 나오고, 스토캐스틱은 조정(눌림/반등)이다.** 이평선 힘 > 스토캐스틱 힘. 단, 배열 상태에 따라 에너지 크기가 달라져 파동 패턴이 단순 조정인지 추세 전환인지가 갈린다(§6).

## 2. 다수결 공식

```
[F2-a] 5개 이평(5,20,60,120,240) 중 3개 이상 상승 → 상승 충격파/추세 진행
[F2-b] MA60·120·240 모두 상승 → 완전 상방 (큰 하락도 결국 회복)
[F2-c] MA5·20만 상승, MA60·120·240 하락 → 하락추세 내 반등에 불과
[F2-d] 3개 파동(소/중/대) 중 2개 상승 → 가격 상승
[F2-e] MA20 vs MA60 상대 위치 → 큰 흐름의 방향 결정
        (MACD 근사: MACD선 ≈ MA20, 0선 ≈ MA60. 다이버전스 신뢰도는 MACD가 최상)
```

## 3. 패턴 → 이평선 기울기 전환 공식 (연쇄)

```
[F3-a] 캔들 쌍바닥  → 하락하던 MA10의 기울기를 돌린다
[F3-b] MA5 쌍바닥   → 하락하던 MA20의 기울기를 돌린다
[F3-c] MA10 쌍바닥  → 하락하던 MA60(추세선)의 기울기를 돌린다
[F3-d] MA5 쌍바닥은 MA20을 돌파시키고, 캔들을 MA60까지 도달시킬 수 있다
        → 추세 전환의 시발점이 될 수 있다
```
(쌍봉은 전부 대칭. 천장패턴 ↔ 바닥패턴, 상승 ↔ 하락)

## 4. 파동 패턴 → 가격 도달 범위 공식

```
[F4-a] 소파동 쌍바닥(쌍봉)  → 캔들이 MA10~MA20 까지 도달
[F4-b] 중파동 쌍바닥(쌍봉)  → 캔들이 MA20~MA60 까지 도달
[F4-c] 대파동 쌍바닥(쌍봉)  → 캔들이 MA60~MA120 까지 도달
```
범위 내 정확한 도달 지점 보정 변수: ① 이격도(두 바닥 간 저점 차이가 크면 약함) ② 첫 바닥의 거래량 ③ 대파동 기울기(가파른 역방향 기울기면 얕게 도달).

## 5. 멀티 타임프레임 등가·프랙탈 공식

```
[F5-a] 이평선 등가 (24h 산수): 일봉 MA10 = 4시간봉 MA60 = 1시간봉 MA240
[F5-b] 일봉 MA10의 방향 예측 = 4시간봉 MA10의 쌍바닥/쌍봉 확인과 동일
[F5-c] 파동 등가 (프랙탈): 상위 프레임의 소파동 = 기준 프레임의 대파동
        (예: 주봉 소파동 = 일봉 대파동)
[F5-d] 파동 1개가 만들어질 때 그 내부에서 한 단계 작은 파동은 최소 쌍바닥/쌍봉을 만든다
[F5-e] 어떤 파동의 쌍바닥(쌍봉) 발생 → 한 단계 작은 파동이 3파로 움직인다
        (대파동 쌍봉 → 중파동 1파 하락·2파 반등·3파 하락 / 소파동 쌍바닥의 경우는
         하위 TF로 내려가 그곳의 대파동 쌍바닥으로 읽고 그 아래 중파동의 3파를 본다)
[F5-f] 파동 세팅값 = 기간 해석: (k,s,d)에서 추세 방향 k개 캔들 + 반대 방향 s개 캔들
        (대파동 20-10-10: 추세대로 ~20봉, 조정 ~10봉 / 중파동 10-5 / 소파동 5-3)
```

## 6. 배열 조건부 유효성 공식 (실전 역학관계 ①~⑤)

### ① 상승추세 매수 (전제: MA120-240 GC 이후 정배열)
```
[F6-1a] 캔들 > MA20            : 소파동 LL 쌍바닥도 상승 가능
[F6-1b] MA60 < 캔들 < MA20     : 소파동 LL 쌍바닥은 상승 불가
[F6-1c] MA60 < 캔들 < MA20     : 소파동 HL 쌍바닥은 상승 가능
[F6-1d] MA60 < 캔들 < MA20     : 중파동 LL 쌍바닥도 상승 가능
```

### ② 하락추세 매도 (전제: MA120-240 DC 이후 역배열) — ①의 완전 대칭
```
[F6-2a] 캔들 < MA20            : 소파동 HH 쌍봉도 하락 가능
[F6-2b] MA20 < 캔들 < MA60     : 소파동 HH 쌍봉은 하락 불가
[F6-2c] MA20 < 캔들 < MA60     : 소파동 LH 쌍봉은 하락 가능
[F6-2d] MA20 < 캔들 < MA60     : 중파동 HH 쌍봉도 하락 가능
```

### ③ 변곡점 단기 매매 = §4의 도달 범위 공식 적용

### ④ 변곡점 추세전환 — 공매도 (정배열이 위에서부터 무너지는 단계별 요구 조건)
```
[F6-4a] (캔들-5-10-20-60) 정배열 + (60-120-240) 역배열
         : 중파동 쌍봉 + 소파동 쓰리봉 → 전환 가능
[F6-4b] (캔들-5-10-20-60-120) 정배열 + (120-240) 역배열
         : 대파동 쌍봉 + 중파동 쓰리봉 → 전환 가능
[F6-4c] MA240까지 완전 정배열
         : MA5 쌍봉 + 대파동 쓰리봉이 나와야 전환 가능
           또는 MA10 HH 쌍봉 + 대파동의 깔끔한 LH 쌍봉 (하락 다이버전스)이어야 전환 가능
         : 이 대파동 쌍봉의 하방 에너지를 막으려면 중파동의 깔끔한 쌍바닥/쓰리바닥 필요
```

### ⑤ 변곡점 추세전환 — 공매수: ④의 완전 대칭 (역배열이 아래에서부터 회복, 쌍봉↔쌍바닥, HH↔LL, LH↔HL)

핵심: 추세가 강하게 정렬되어 있을수록 전환에 필요한 파동 패턴의 급이 올라간다 (중파동 쌍봉 → 대파동 쌍봉 → MA5 쌍봉+대파동 쓰리봉). 역으로, 이평선 쌍봉·쌍바닥 없이도 충분한 급의 스토캐스틱 에너지가 축적되면 추세는 바뀔 수 있다.

## 7. 패턴 판정 보조 공식

```
[F7-a] 깔끔한 쌍봉의 정의: 고점도 낮아지고(LH) 저점도 낮아져야(LL) 한다
        (쌍바닥은 대칭: HL + HH). 애매하면 그 구간은 매매하지 않는다
[F7-b] 애매한 쌍봉 → 쓰리봉 대기. 쓰리봉 = '강력한' 추세전환 패턴 (에너지 소진)
        진입 위치: 대파동 쓰리봉 끝자락에서의 소파동 쌍봉 (쓰리바닥은 대칭)
[F7-c] 너비 규칙: 직전 외바닥(외봉)의 파동 너비가 현재 쌍바닥(쌍봉) 너비보다 작으면
        그 외바닥을 1번 바닥으로 세지 않는다 — 현재 위치가 사실상 1번 바닥
[F7-d] 너비가 부족한 쓰리봉 / 3번째 봉우리가 과매수에 재진입하는 쓰리봉
        → 마지막 파동이 한 번 더 나온다 (불트랩 가능)
[F7-e] 애매한 쓰리봉 = 그 파동의 '강한 쌍봉'과 같다 → 조정의 최대 한계치까지 간다
        판별법(다중스크린): 한 단계 하위 TF로 내려가 대파동으로 확인
        (소파동보다 대파동의 신뢰도가 높다)
[F7-f] 독수리 패턴: 어떤 파동의 3번째 바닥이 2번째보다 낮아지는 비정상 쓰리바닥인데,
        한 단계 위 파동이 그 시점에 쌍바닥을 만드는 경우 → 강한 상승.
        저점 상승을 기다리지 말고 전저점 지지대를 진입가로 설정
[F7-g] 다이버전스 짝 (위계상 인접 쌍끼리 비교):
        소파동 ↔ 캔들  /  중파동 ↔ MA5  /  대파동 ↔ MA10
[F7-h] 추세 시작점(엘리어트 1파) = 이평선의 쌍바닥/쌍봉 직후 첫 파동.
        기본은 MA5 쌍바닥, 상승장급 추세는 최소 MA20 쌍바닥, 그보다 큰 추세는 MA60 쌍바닥
[F7-i] 힘의 근원 추적: 현재 TF의 급락/급등이라도 그 에너지의 출처는 상위 TF의
        다이버전스·쌍바닥·쌍봉일 수 있다 — 어떤 차트를 볼지는 힘의 근원이 정한다
```

## 8. 공식 간 관계 (한 장 요약)

```
힘의 위계(§1) ──┬── 다수결(§2): 추세 판정
                ├── 연쇄(§3): 작은 패턴이 큰 이평선 기울기를 돌림
                ├── 도달 범위(§4): 파동 급 → 가격 목표 구간
                └── 배열 조건(§6): 같은 패턴도 배열·캔들 위치에 따라 유효/무효
프랙탈(§5): 위 모든 공식이 모든 타임프레임에서 자기유사적으로 반복
판정 보조(§7): 패턴의 진위(깔끔함·너비·쓰리봉·독수리)를 가려내는 필터
```

## 9. 코드베이스 매핑 (WaveEnergyHelper 기준)

**이미 구현됨**
- [F5-c] 상위 소파동 = 기준 대파동 → MTF 검증 (`resolve_upper_frame`, x6 폴백 포함)
- 쌍바닥/쌍봉 검출기 (스토캐스틱 파동 기준, 반전 대칭 구현)
- 정배열/역배열 판정 (`get_ma_alignment`) — 단, §6의 전제인 "구간별 배열"(120-240만 역배열 등)은 미구현

**다음 구현 후보 (우선순위 제안)**
1. **HL/LL·HH/LH 분류** — §6, §7-a의 전제. 현재 검출기는 쌍바닥 여부만 기록하고 두 바닥의 고저 관계를 구분하지 않음. `stoch_db_*` 확정 시 1·2번 바닥 값 비교 메타데이터 추가 필요
2. **구간별 배열 상태** — §6의 조건식(캔들-5-10-20-60 정배열 + 60-120-240 역배열 등). `get_ma_alignment`를 전체 일괄 판정에서 구간 분할 판정으로 확장
3. **캔들 위치 조건** — 캔들이 MA20/MA60 대비 어디에 있는지 (§6-①②의 분기 키)
4. **도달 범위 출력** — [F4] 공식으로 verdict에 목표 구간(MA10~20 등) 추가
5. **쓰리봉/쓰리바닥** — 현재 tb만 부분 존재. [F7-b]의 "강력한 전환 패턴" 판정과 [F7-d] 너비 규칙
6. **다이버전스 짝** — [F7-g]. 이평선 피봇 검출(이평선 쌍바닥)이 선행 과제

**정합성 주의사항**
- 책의 이평 체계는 5-10-20-60-120-240인데 앱 `MA_PERIODS`는 [5,10,20,40,60,80,120,240]로 40·80이 추가되어 있음. §2 다수결·§6 배열 조건을 구현할 때는 책의 6개 체계만 사용해야 공식이 성립 (40·80은 표시용으로만 유지할지 결정 필요)
- §3·§6의 "이평선 쌍바닥"은 가격이 아닌 **이평선 자체의 패턴** — 스토캐스틱 피봇 검출기와 별개로 이평선 시계열에 대한 피봇/패턴 검출이 필요
- [F2-a]는 5개 체계(10 제외), [F1-a]는 6개 체계로 책 내에서 집합이 다름 — 구현 시 어느 쪽 기준인지 김박사 결정 필요

## 10. [F8] 이격도 극단 법칙 (실증 발견 → 검토자 승인, 2026-06)

출처가 책이 아닌 첫 공식. 실데이터 검증 라운드에서 발견되어 김박사가 이론으로 승인함.

```
[F8-a] 변곡(④⑤) hit의 형성 봉은 이평선 이격도의 극단에서 형성된다
        이격도 = Σ|MAi−MAj| / (15 × close), 코어 6이평 쌍별 거리 합 정규화
[F8-b] 두 유형: 응축형 (전역 백분위 ≤25 — 수렴 후 전환, 천장/돌파 준비형)
                과이격형 (백분위 ≥75 — 과대 이격 회귀, 폭락 V바닥형)
[F8-c] 중간 구간(25~75) 형성 hit은 통계적으로 드묾 → 신뢰도 참고 정보
```

실증 근거 (ETHUSDT 4h, 1,600봉): 엔진 HIT 8건 중 양쪽 꼬리 7건(87.5%) vs 무작위 12.5%.
정답 천장 Z1·Z3는 응축 극점(0.1%·1.5%), 정답 바닥 Z2는 과이격 극점(99.8%)에서 형성.
현재 지위: **주석(annotation)** — hit 표기에만 사용, 게이트·점수 아님.

## 11. 구현 현황 갱신 (2026-06-07 기준)

§9 작성 이후 구현 완료: HL/LL·HH/LH kind 분류(쌍·쓰리 패턴 전체) / CORE_MA_PERIODS
판정 분리 / 이평선 쌍바닥·쌍봉 검출기 / 쓰리봉·쓰리바닥 / 구조 상태 U1~D3 /
①② 추세 공식 8행 + ④⑤ 변곡 공식 8행 (RULE_TABLE·TRANSITION_RULE_TABLE) /
④⑤ 형성 시점 = 첫 피봇 봉(검토자 확정 의미론, first_pos 기록) / MA 원자 공식 윈도 96 /
이격도 지표·[F8] 주석 / 바이낸스 페이지네이션 / 검증 도구(sweep·gt_trace·dispersion_obs).

## 13. 같은 TF의 에너지 관계 관측 ER1 (2026-10-28)

사용자 제안인 ‘대파동 하락 중 소파동 쌍바닥을 기다린다’를 관측 규칙으로 구현했다. 대파동과 MA10은 F7-g의 비교 짝으로 쓰되 방향의 수학적 동치로 취급하지 않는다. 사용자가 말하는 대파동 하락은 `K(t)<K(t−1)`로 정의하고, 실제 MA10 방향은 `(C_t−C_(t−10))/10`으로 따로 계산한다.

현 대파동 방향 구간에서 소파동 반대 패턴의 대기→후보→확정을 관측하고 대파동 방향 변화·MA10 동행을 확인한다. 상승 구간은 쌍봉을 보는 대칭이다. 기존 과매도/과매수·폭 비교 검출기를 사용하며, 임의 넥라인·피봇 정의로 바꾸지 않는다. 반대 패턴 확정 없이 대파동이나 MA10 방향이 바뀌면 해석 재검토 대상으로 남긴다. 소파동 쌍바닥 이전까지 반드시 하락한다는 법칙을 확정한 것은 아니다.

근거와 범위: [스토캐스틱 공식 계산식](https://www.tradingview.com/support/solutions/43000502332-stochastic-stoch/)은 고저 범위 안의 종가 위치를 평활하며, [SMA 정의](https://www.tradingview.com/support/solutions/43000696841-simple-moving-average/)는 종가 평균이다. 둘의 방향이 항상 같지는 않다는 것은 계산식으로부터의 추론이다. 실제 지표 합성 반례와 마감·구간·후보 취소 계약을 테스트한다. 별도 수익 성과·인과 법칙 검증은 수행하지 않았다.

구현: `analysis/wave_energy_relation.py`, `display/energy_frames.py`, `display/energy_observation.py`. 사용 위치와 4d 봉 계약은 [앱 사용법](앱_사용법.md), [시간·캐시 계약](시간_캐시_계약.md)에 기록했다.

## 14. 상위 추세를 먼저 확인하는 HT1 (2026-10-29)

사용자 정책으로 **4일봉 MA10을 주 기준**, **일봉 MA60을 전체 추세 교차 확인**에 사용한다. 두 기준이 하락 중이면 시간봉 상승을 우선 역추세 반등으로, 두 기준이 상승 중이면 시간봉 하락을 조정으로 해석한다. 시간봉 반등이나 쌍바닥만으로 상위 추세 전환을 확정하지 않는다. 두 기준이 충돌·평탄·자료 부족이면 이 분류를 보류한다.

방향은 각 기준 MA의 1봉 차분이며, 종가가 MA 위에 있다는 사실과 구분한다. 현재 TF의 MA 방향과 반대 방향 전환 후보도 구분해 표시한다. 관측 범위가 주 기준보다 긴 주봉·일봉 MA60 등을 단순 하위 반등으로 분류하지 않는다. 이는 해석 순서를 정하는 정책이며 높은 TF의 성공 확률이 항상 높다는 실증 법칙을 새로 승인한 것이 아니다.

4d MA10은 명목상 40일 범위이지만 4일 간격 종가 10개의 평균이므로 일봉 MA40과 값·갱신 주기가 다르다. 일별 종가가 1~40이면 4일 끝 종가 평균은 22, 매일 종가 평균은 20.5다. 다만 연속 4일봉·같은 종가 원천·정렬된 공통 마감에서는 두 MA의 1봉 차분이 모두 `C_t−C_(t−40일)`에 비례해 부호가 같다. 이 조건에서도 방향이 반드시 다르다고 설명하지 않는다. 이는 [SMA 정의](https://www.tradingview.com/support/solutions/43000696841-simple-moving-average/)에서 계산한 관계다.

상위 TF 진행값을 확정 추세처럼 사용하지 않는다. [공식 HTF 확정성 설명](https://www.tradingview.com/pine-script-docs/concepts/other-timeframes-and-data/#avoiding-repainting)에 따른 시점 문제를 고려해 프로젝트의 실제 마감·최종값 확보 계약을 유지한다. 조회 시각은 같되 두 기준의 실제 마지막 마감과 다음 확인 시각을 따로 표시하며, 먼저 만료되는 기준부터 재확인한다.

구현: `analysis/trend_context.py`, `display/trend_context.py`. 기존 패턴·순위·푸시 판정은 유지하고 해석 맥락을 추가한다.

## 15. 상승 추세 안의 변곡 준비 TP1 (2026-10-29)

HT1의 MA10 상승 판정과 별도로, 같은 4일봉 마감 자료에서 상승 탄력의 약화와 두 단기 관계를 함께 관찰한다. 마지막 완성 4일봉을 `t`라 할 때 다음 조건이 모두 참이면 `BEARISH_PREP`, 즉 **상승 추세 안의 변곡 준비**로 표시한다.

1. MA10의 직전 1봉 변화량을 `delta_prev=(C_(t−1)−C_(t−11))/10`, 현재 변화량을 `delta_now=(C_t−C_(t−10))/10`으로 계산해 `0 < delta_now < delta_prev`인지 확인한다.
2. 같은 마감봉의 `MA5 < MA10`을 확인한다.
3. 같은 마감봉의 `MACD선 < 시그널선`을 확인한다. MACD는 프로젝트 설정의 EMA 12·26, 시그널 EMA 9와 `adjust=False`를 사용한다.

현재 두 선의 위·아래 관계와 교차 사건은 구분한다. MA5·MA10 데드크로스는 직전 봉의 차이가 0 이상이고 현재 차이가 음수일 때이며 MACD선·시그널선도 같은 교차 정의를 쓴다. 각 교차의 실제 마감 시각·몇 봉 전인지를 따로 표시하므로 두 교차가 같은 봉에 발생할 필요는 없다. 이전부터 아래에 있던 상태를 이번 봉의 데드크로스로 표시하지 않으며, 확보한 구간에 사건이 없으면 교차 시각을 추정하지 않는다.

이 상태에서도 HT1의 실제 MA10 방향은 상승으로 유지한다. MA10이 하락으로 바뀐 경우는 별도의 실제 방향 관측이다. 준비 조건 중 하나가 깨지면 준비 상태를 해제하고, 시간봉 조정 분류에도 상위 기준의 변곡 준비가 동반됐음을 덧붙인다. 이 조합만으로 하락 전환을 확정하지 않는다.

관측에는 연속된 완성 4일봉이 최소 35개 필요하다. 기존 4일 차트의 최초 부분봉은 관측·최소 봉수·교차 사건에서 제외하되 `energy_macd_seed`의 종가·실제 마감 시각으로 보존하여 MACD의 EMA 초기 계산에만 사용한다. 같은 조회창의 원래 차트와 MACD 계산 이력을 맞추기 위한 처리다. 누락·결측·메타데이터 불일치·미마감·갱신 지연이면 준비 판정을 보류하며, 재확인은 HT1 기준 중 가장 빠른 다음 마감을 따른다.

근거와 범위: [SMA 정의](https://www.tradingview.com/support/solutions/43000696841-simple-moving-average/)의 종가 평균에서 MA10 차분식을 계산했다. [MACD 공식 설명](https://www.tradingview.com/support/solutions/43000502344-moving-average-convergence-divergence-macd-indicator/)은 MACD·시그널·히스토그램의 계산과 MACD가 시그널 아래일 때 상승 모멘텀이 감소할 수 있다는 해석을 설명한다. 이를 결합한 TP1은 사용자가 제안한 관찰 정책이며, 조합의 예측 확률·수익 성과 또는 현재 BTC 시세를 확인한 결과는 아니다. 기존 신호·순위·게이트·외부 푸시 판정은 변경하지 않는다.
