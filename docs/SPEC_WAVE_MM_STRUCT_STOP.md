# SPEC_WAVE_MM_STRUCT_STOP — 자금 관리 3라운드: 구조 손절 vs 고정 −3% (frozen)

작성: 2026-09-04. 사전등록 스펙. 실행 중 판정 기준·손절 정의·버퍼를 수정하지 않는다.

## 0. 가설의 출처와 정직성 조항

- MM-R1의 메커니즘 진단: −3% 고정 손절의 실패 양상은 승자 청산이 아니라
  되돌림 직전 매도 (실현 −3.25% vs 방치 −2.78%, 손절 트레이드의 85%는 어차피
  음수). 평균회귀형 진입(바닥 패턴)과 고정 % 손절이 구조적으로 싸운다는 진단.
- 본 가설은 폭 조정이 아니라 계열 교체다: 책의 원칙 "진입 근거가 소멸하면
  청산" — 쌍바닥 진입의 근거 소멸은 패턴 저점 이탈이다. 가격 거리가 아니라
  구조에 손절을 붙인다.
- **정직성 조항: 이 가설은 같은 표본의 진단에서 동기를 얻었다.** MM §5 폭
  곡선에서 값을 고른 것은 아니지만(곡선은 % 손절 계열, 본 가설은 다른 계열),
  같은 데이터 위의 검정이라는 한계는 남는다. 확인의 최종 수단은 병행 배선되는
  전방 섀도 추적이며, 본 라운드의 ACCEPT는 "섀도 추적 대상 승격"까지다.
- MM-R1처럼 CI가 간발로 걸리는 결과가 나와도 재설계·재시도하지 않는다.

## 1. 고정 정의

- 시뮬레이터·모집단·체결·비용·1포지션·20봉 청산: MM/SZ 라운드와 동일.
  사이징은 SZ-R1 판정에 따라 고정 5%.
- STRUCT 손절:
  - reference_low = 진입 봉 직전에 확정된 마지막 swing low
    (기존 swing 검출 함수 그대로 — is_tb_proxy가 소비하는 swing_lows 산출
    경로를 재사용, 신규 검출기·파라미터 금지, asof: 진입 시점 이전 확정분만)
  - 손절선 = reference_low × (1 − 0.005)
  - 버퍼 0.5% 고정. 근거: SZ-R0 실측 atrp 중앙값 0.998% — LTF 한 봉 전형
    범위의 절반으로, 저점 정확 터치 소거를 피하면서 손절 심화를 최소화하는
    사전 선택. 대안 값 탐색 금지.
  - reference_low 미검출 이벤트: BASE(−3% 평단) 적용, 비율을 §3에 보고.
  - 손절선이 진입가 위인 퇴화 케이스(저점이 진입가에 근접): 발생 시 해당
    트레이드는 BASE 적용, 건수 보고.
- BASE: 평단 −3% (현행 실규칙, MM 라운드와 동일)

## 2. SS-R0 — 검정력 관문 (go/no-go)

- 계측: reference_low 검출률, 구조 손절 거리(진입가 대비 %) 분포,
  −3%와 1%p 초과로 다른 트레이드 비율.
- GO 조건 (둘 다):
  1. 검출률 ≥ 80%
  2. 구조 거리가 −3%와 1%p 초과로 다른 트레이드 ≥ 30%
- NO-GO → 종료, 기록: "이 모집단에서 구조 손절은 고정 −3%와 구별될 만큼
  다른 손절선을 만들지 않음."

## 3. SS-R1 — 판정

- 주 비교 (단 하나): Δ = G(STRUCT) − G(BASE), G = 비용 차감 로그 성장률 합
  (MM-R1과 동일 지표 — 손절 계열 내 비교라 투입량 오염 없음)
- 성공 기준 (전부 충족 시에만 "STRUCT 우위 — 섀도 추적 승격"):
  1. Δ > 0, 월 클러스터 부트스트랩 95% CI가 0 배제 (2000회, 시드 기재)
  2. 트레이드 ≥ 100 (양쪽)
  3. half-split 양쪽 같은 부호
  4. 1h·6h 스트림 같은 부호
- Δ < 0으로 1·3·4 충족 시 "STRUCT 열위". 그 외 식별 불가.
- 어떤 판정이든 실운용 반영은 사용자 결정. ACCEPT의 효력은 섀도 추적의
  주 감시 대상 지정이며, 실규칙 교체 권고는 전방 데이터 이후로 유보한다.
