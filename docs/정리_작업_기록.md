## 구조와 호환성

```text

charts.lw_builder → lw_config / lw_payload / lw_templates
```

`display`의 기존 공개 함수와 `scripts/push_alarms.py`의 기존 실행 명령을 유지했습니다. 숫자형 정규화는 `data/numeric.py`, KST 표시 헬퍼는 `utils/time_display.py`로 옮기고 이전 import 경로도 유지했습니다.

고정 `validation/wave_ma60_turn_probe.py`, 게이트 정의 파일, 지표, `config/settings.py`의 내용은 유지했습니다. 운영은 추출한 순수 신호 계산을 사용하므로 원본 계측 스크립트의 로그·경고 전역 설정을 실행하지 않습니다.

`config/refactor_provenance.json`은 이동한 **94개 함수·클래스**의 원본 커밋·경로·AST 해시를 기록합니다. 원본 본문과 다른 함수를 기대값만 바꿔 통과시키지 않았습니다. 구조에 대한 기존 소스 검사는 새 구현 위치를 검사하도록 갱신했고 수치·시각·상태 기대값은 유지했습니다.
