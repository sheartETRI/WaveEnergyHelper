## MTF 설명 카드 반영 (2026-10-28)

사용자 요청에 따라 기준 TF 레이더에 선정 이유·현재 MA60 방향·상하위 관계·다음 마감과 비교 종가·관찰 기간·자료 상태를 함께 표시했습니다. 관찰/상위/하위 차트 이동을 제공하고, 레이더가 선정한 TF·이유를 차트에서도 유지합니다. 차트 시간봉 변경은 관찰 대상을 바꾸지 않으며 별도 설명 TF 선택기와 임의 TF 대체는 제거했습니다. 화면에 계산한 설명을 복사 텍스트와 CLI에 그대로 사용합니다.

설명은 OHLCV를 먼저 마감 기준으로 자른 후 지표·후보를 재계산합니다. 마지막 원본 봉은 수신 당시 미완성일 수 있으므로 후속 봉이 도착한 구간까지만 사용해, 캐시 시간이 지났다는 이유만으로 마감값으로 승격되지 않도록 했습니다. 누락·결측·갱신 지연·상하위 미적재와 양방향 관찰을 명시하며, 기존 오른쪽 라벨 합성 2d·4d·2w의 설명은 보류합니다.

설명 모델·시각 표시는 `display/mtf_guidance_model.py`, 프레임 준비·화면·세션 변화 안내는 `display/mtf_guidance.py`에 둡니다. 신호·20봉 창·순위와 외부 푸시 정의는 유지합니다. 변화 안내는 사용자 새로고침 시 세션 내 비교이며 자동 발송을 추가하지 않았습니다. 차트 첫 화면은 전체 TF를 추가 조회하지 않습니다.

종목별 마지막 레이더 view를 저장해 차트에서는 읽기 전용으로 표시합니다. 마지막 조회 시각을 붙이고 확인 시각이 지나면 다음 조건·잔여 기간을 재조회 안내로 바꿉니다. 레이더 미조회·대상 없음·자료 부족을 구분하며 새 조회에서 대상이 없으면 이전 카드를 제거합니다. 차트 적재가 실패해도 관찰 안내와 레이더 접근을 유지합니다.

최종 `.venv-runtime/Scripts/python.exe -m pytest --suite runtime -q` 결과는 **426 passed, 12 skipped, 2 deselected**입니다. 새 설명 검사 39개는 마감·월 경계·가격 비교값 정밀도·상하위 충돌·자료 보류·캐시 미완성 봉·미마감 가격 변화의 격리·화면/복사 일치·상태 변화·실제 차트 이동, 차트 TF와 독립된 선정 이유 유지·읽기 전용 재생·대상 없음 시 이전 카드 제거·지난 확인 조건 보류를 확인합니다. 12개 skip은 미설치 Plotly의 이전 엔진 비교이고, 2개 제외는 실제 네트워크·브라우저 검사입니다. 변경 스펙은 [§10.1](SPEC_SWEEP_RECLAIM.md), 사용 위치는 [앱 사용법](앱_사용법.md)에 정리했습니다.

## 대·소파동 에너지 관계 ER1 (2026-10-28)
