## 후보 1 — 60MA 전환 전략 (사용자 제안, 2026-09-19)

### 배경: 왜 이것이 새 질문인가
V2가 기각한 것은 "상위 TF 대파동 바닥 상태 → **20봉 뒤 수익**"이다.
책(5장 사거리표)이 주장한 목표인 **이평 도달**로는 한 번도 평가된 적이
없다. 또한 이 전략은 진입 시점에 손절(패턴 저점)과 목표(60MA 방향)가
모두 정해져 손익비를 사후 선택 없이 계산할 수 있다 — 기존 라운드들이
전부 기대값(평균 수익)으로만 판정한 것과 다른 각도다.

### 전략 (사용자 서술 그대로)
1. 스토캐스틱 **대파동(20,10,10)이 쌍바닥** → 후보 상태 진입
2. 하방이던 **60MA가 상방으로 전환**되는지 관찰 → 전환 확인 시 진입
3. **60MA가 상방을 유지하는 한 보유** (시간 청산 없음)
4. 60MA가 하방 전환될 가능성 = **대파동 쌍봉 또는 10MA 쌍봉** 발생 시 매도
5. 손절: 패턴 저점 × 0.995 (SS 라운드에서 ACCEPT된 구조 손절 승계)

### 사전 고정 정의 (2026-09-19 확정 — 스펙 동결 시 그대로 승계)
- **TF**: 1h 기준으로 서술됨. 주 검정은 1h, 4h는 보조 재현 확인.
- **"60MA 방향"**: MA60(t) > MA60(t−1) (F2-b의 기울기 정의 승계, 창 1봉).
  전환 = 직전 봉 하방 → 당해 봉 상방. 플래핑은 한계로 보고.
- **"관찰 창"**: 쌍바닥 확정 후 몇 봉 안에 60MA 전환이 와야 유효한가.
  고정: 20봉 (사전등록 값, 변경 금지).
- **"10MA 쌍봉/쌍바닥"**: 10MA 쌍봉/쌍바닥 = 가격 10MA 자체의 쌍봉/쌍바닥
  (사용자 확정 2026-09-19). 스토캐 대파동(20,10,10)과 형태는 유사하나
  힘의 크기는 이평선 > 스토캐스틱 (책 F1 대원칙, V2·확인 검정의 수치
  위계와 일치).
- **청산 우선순위**: 손절선과 매도 신호가 같은 봉에서 충돌 시 손절 우선.
- **미청산 포지션 처리**: 관측 구간 종료 시점 미청산 건의 평가 방법.

### 판정 설계
- 주 비교: 이 전략 vs BASE(F2-b 게이트 통과 이벤트 + 20봉 시간 청산)
- **주 판정 지표는 G(비용 차감 로그 성장률 합) 1개로 고정한다.**
  보유 기간이 다른 전략 간 트레이드당 기대값 비교는 불공정하므로
  사용하지 않는다. 승률·손익비·보유 기간 분포는 보조 보고이며 판정에
  쓰지 않는다.
- **매도 조건 결합**:
  (a) 대파동 쌍봉 OR 10MA 쌍봉 — 주 판정.
  (b) 10MA 쌍봉 단독 — 사전등록된 보조 비교.
  셋 이상 조합 스윕 금지.
- 기준 4개(CI·n≥100·half-split 동부호·TF 재현)는 기존 라운드 관례 승계
- **표본 우려**: 조건이 겹겹이라(대파동 쌍바닥 ∧ 60MA 전환) n이 작을 수
  있음 → R0 검정력 관문 필수(기대 n ≥ 100 미달 시 NO-GO)

### 후보 1 변형 (2026-09-19 추가, 사용자 제안)
계측 REPORT_MA60_TURN_PROBE(전환율 1h 40.7% / 4h 41.3%, 후보의 약 59%는
20봉 내 미전환)를 본 뒤 제안된 변형이다. **탐색 결과를 본 뒤의 제안임을
명기한다** — 원안(V1)과 동등한 지위가 아니며, 검정 시 다중 비교 보정
대상이다.

- **V1 (원안, 주 판정)**: 대파동 쌍바닥 → 20봉 내 60MA 전환 시 진입
- **V2 (진입 조건 강화)**: 대파동 **삼중바닥** → 60MA 전환 시 진입
  가설: 쌍바닥은 전환의 시작점이고 삼중바닥이 확정 신호라면,
  V2의 전환율과 G가 V1보다 높아야 한다
- **V3 (신호 선행)**: 대파동 쌍바닥 → 20봉 내 **40MA** 전환 시 진입
  (그 외 전부 V1과 동일, 청산의 60MA 조건은 유지)
  가설: 60MA 전환을 기다리면 중앙 7~8봉의 지연이 발생하므로,
  더 짧은 이평의 전환으로 앞당기면 G가 개선된다

판정 규칙(사전 고정):
- 주 판정은 V1 단독. V2·V3는 **사전등록된 변형 비교**이며, 셋 중 최고를
  고르는 방식의 판정을 금지한다.
- V2·V3가 V1을 상회하더라도 그 자체로 채택 근거가 아니며, 다중 비교를
  반영해 CI 기준을 보수적으로 적용한다(구체 방법은 스펙 동결 시 사전 고정).
- 이평 기간(40/60) 추가 스윕 금지 — V3는 40MA 하나만이다.

- **V4 (진입 조건 중첩)**: 대파동 쌍바닥 ∧ (MACD 쌍바닥 또는 RSI 쌍바닥)
  → 20봉 내 60MA 전환 시 진입. 그 외 V1과 동일.
  제안 배경: 전환율 40%를 조건 중첩으로 높일 수 있는가 (2026-09-19,
  계측 결과를 본 뒤 제안 — V2·V3와 같은 지위).
  **사전 경고(기록)**: V2 라운드는 동일 구조(컨텍스트 위에 파동 상태
  중첩)에서 희석을 관측해 REJECT했고, 이들 지표는 같은 가격의 평활
  함수라 종속성이 높다. 전환율 상승이 관측되더라도 건수 급감의 산물일
  수 있다.
  **판정 기준(사전 고정)**: 전환율 단독으로 판정하지 않는다. 주 지표는
  V1과 동일하게 G이며, 보조로 (전환율, 진입 건수, 기회비용 = 놓친
  V1 진입 중 수익이었던 비율)을 함께 보고한다. 전환율만 높고 G가
  V1 이하이면 개선이 아니다.
  중첩 대상은 MACD·RSI 두 지표만 — 다른 지표 추가 스윕 금지.

변형은 V2·V3·V4로 마감한다. 추가 변형은 다중 비교 보정 문턱을 높여
기존 변형의 검정력을 훼손하므로, 2027-03 열람 전까지 더 추가하지 않는다.

## 후보 5 — 40MA 전환 진입 전략 (2026-09-19, 사용자 실전 규칙)

### 지위
**사용자가 현재 실제로 사용 중인 트레이딩 규칙**이다. 후보 1(V1~V4)이
스토캐 대파동 쌍바닥에서 출발하는 계열인 것과 달리, 본 후보는 가격
이평선에서 출발하고 진입 시점이 40MA다. 변형 마감 선언(V2·V3·V4)은
후보 1 내부에 적용되며 본 후보는 별도 계열이다.

### 전략 정의 (사용자 확정 2026-09-19)
1. **진입 트리거** (둘 중 하나):
   - 가격 10MA 자체의 쌍바닥, 또는
   - 다이버전스 = 스토캐 대파동(20,10,10) 저점은 높아지는데 가격 저점은
     낮아지는 것 (후보 2와 동일 조건 — 후보 2는 이 조건 단독의 효과를,
     본 후보는 이 조건이 포함된 전체 전략을 검정한다)
2. **진입 시점**: 40MA가 하방→상방 전환될 때 (60MA 전환을 기다리지 않음)
3. **필수 조건**: 5MA가 10MA를 골든크로스 (충족하지 않으면 진입 없음)
4. **컨텍스트 조건**: 장기 이평선(120·240·480·960)이 현재가 **위에** 위치
   — 그쪽으로 끌어당기는 힘이 남아 있다는 해석
   - **기준 TF (사용자 확정 2026-09-19)**: 장기 이평선은 진입 TF 자체의
     것으로 본다 — 1h 진입이면 1h의 120·240·480·960. 사용자 서술은
     "특정 타임프레임 전부 다 된다"(프랙탈)이나, 검정은 TF를 고정해야
     하므로 진입 TF 내부 기준으로 단일 고정한다. 다른 TF의 장기선을
     참조하는 변형은 검정하지 않는다(스윕 금지).
   - 480·960은 현재 설정에 없어 스펙 동결 시 산출 경로를 추가해야 하며,
     그 근거를 스펙 §0에 명기한다(1h 기준 960봉 ≈ 40일로 데이터는 충분).
5. **확인 과정 (진입 조건 아님, 관찰·보고 항목)**: 진입 후 60MA도 따라
   상방 전환되는지
6. 손절·청산은 스펙 동결 시 확정 (후보 1의 구조 손절 승계 여부 포함)

### 기존 결과와의 긴장 (반드시 함께 기록)
- 조건 4는 **위치** 조건이고 검증된 F2-b는 **방향**(장기 이평 동시 상승)
  조건이다. 장기 이평이 현재가 위에 있는 국면은 F2-b가 닫히는 국면과
  겹칠 가능성이 높다. 즉 본 후보는 "F2-b가 걸러내는 국면에서 기회를
  찾는다"는 주장일 수 있으므로, 검정 시 F2-b 개방/폐쇄별 성과를 반드시
  분리 보고한다.
- 480·960MA는 현재 설정(CORE_MA_PERIODS)에 없다. 40MA와 함께 "표시·미설정
  기간을 판정에 사용하는 근거"를 스펙 §0에 명기해야 하며, 960은 일봉
  기준 약 4년치라 데이터 확보 가능 구간이 제한된다 — R0에서 확인한다.

### 판정 설계 (초안 — 동결 시 확정)
- 주 지표는 후보 1과 동일하게 **G**. 승률·손익비·보유 기간은 보조 보고.
- **R0 검정력 관문 필수·강화**: 조건이 4겹(트리거 ∧ 40MA 전환 ∧ 5/10 GC
  ∧ 장기 이평 위치)이라 표본 급감이 예상된다. 기대 n < 100이면 NO-GO로
  기록하고, 그 경우 "실전 규칙의 기회 빈도가 낮다"는 것 자체를 발견으로
  기록한다(조건 완화로 n을 맞추는 것을 금지).
- 트리거 두 갈래(10MA 쌍바닥 / 다이버전스)는 통합을 주 판정으로 하고,
  갈래별 분해는 보조 보고. 갈래를 골라 판정하지 않는다.
- 이평 기간·조건 조합 스윕 금지. 위 정의 1세트만 검정한다.

### 다이버전스 플래그의 단일 정의 (후보 2·5 공통)
후보 2와 후보 5는 동일한 조건 — 스토캐 대파동 저점은 높아지는데 가격
저점은 낮아지는 것 — 을 사용한다. 정의 분기를 막기 위해:
- **후보 2 스펙을 먼저 동결**하고 거기서 플래그를 정의한다(스토캐 저점
  비교는 기존 stoch_db_kind의 HL 판정을 소비, 가격 저점 비교 기준은
  후보 2 스펙에서 사전 고정).
- 후보 5는 그 플래그를 **import해 소비**한다. 재정의·재구현 금지.
- 후보 2가 NO-GO 또는 검정 불가로 끝나더라도 플래그 정의는 유효하며,
  후보 5는 그대로 소비한다(판정 결과와 정의는 별개다).
