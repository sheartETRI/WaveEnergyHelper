## 0. 핵심 명제 (김박사 원문 요지)

이론의 본질은 추세 매매이며, 추세의 기준은 **60MA**다. 10MA/대파동의 쌍바닥은 매수 신호 그 자체가 아니라 **60MA를 돌릴 수 있는 기준점**이다. 쌍바닥의 기간(폭)이 클수록 발생하는 힘이 크고, 짧으면 60MA가 천천히 돌거나 돌지 못할 수 있다. 상승 지속의 조건은 단 하나 — **60MA의 상승 유지** — 이며, 이를 깨는 것은 10MA/대파동의 쌍봉(및 MACD 쌍봉)이다. 60MA가 120MA를 골든크로스하고 120MA가 상승으로 돌아서면 완연한 상승 추세이며, 120MA를 하방으로 돌리려면 20MA/대대파동의 쌍봉이 필요하다.

## 1. 상응 체계 (확정 — [F1] 위계의 완결)

일반 규칙: **스토캐스틱 (K, K/2, K/2)는 MA(K/2)를 추종한다.** 급 내에서 가격계 신호가 오실레이터 신호보다 힘이 높다.

| 급 | 가격계 신호 | 상응 스토캐 | 비고 |
|---|---|---|---|
| 4 (최상) | MA20 쌍바닥/쌍봉 | 대대파동 (40,20,20) | **신규 4층 — 지표 추가 필요** |
| 3 | MA10 쌍바닥/쌍봉 | 대파동 (20,10,10) | 기존 |
| 2 | MA5 쌍바닥/쌍봉 | 중파동 (10,5,5) | 기존 |
| 1 (하위) | 캔들 쌍바닥/쌍봉 (4봉 교대+HL) | 소파동 (5,3,3) | PHASE4-E 구현 |

추세-트리거 대응 (관측된 ×6 규칙 — 일반화는 관측 후):
- **60MA 추세** ↔ 트리거 = 급3 (MA10/대파동), 60 = 10×6
- **120MA 추세** ↔ 트리거 = 급4 (MA20/대대파동), 120 = 20×6

## 2. 추세 상태 기계 (확정 정의)

```
T0 DOWNTREND : slope(60MA) < 0
T1 BOTTOMING : 급3 쌍바닥 확정 (candidate부터 관찰 개시)
               + 60MA 하락 기울기 약화 (|slope| 축소 추세)
               → 관찰 상태. 폭 계측: width = 두 바닥 피봇 간 봉 수 (힘의 프록시)
T2 TURNING   : 계단식 GC 확인 — ① MA10×MA20 GC → ② MA20×MA60 GC
T3 UPTREND   : slope(60MA) > 0 전환 완료. 이 형성 구간 = 엘리어트 1파
               · 1파 내 하위 3파 국면에서 캔들-60MA 이격 확대 → 2파 조정(이격 해소) [F8]
               · 지속 조건 (유일): slope(60MA) > 0 유지 — 조정 중에도 이것만 확인
T4 STRONG    : MA60×MA120 GC + slope(120MA) > 0 = 완연한 상승 추세

파괴 트리거 (하락 대칭은 전부 미러):
  T3 파괴 : 급3 쌍봉 (MA10/대파동) 또는 MACD 쌍봉 → "빠른 익절" 신호
  T4 파괴 : 급4 쌍봉 (MA20/대대파동)
```

**판정 기준 (확정)**:
- `slope(MA, N)` = MA 현재값 − N봉 전 값의 **부호**. N은 상수 `TREND_SLOPE_N`으로 노출 (MA60/MA120 각각, 초기값 제안: 5 — 김박사 조정 대상).
- MACD 쌍봉 = **MACD선 고점 2개, 둘째 고점 < 첫째 고점 (LH)**. 가격 조건 없음, 시그널선 조건 없음. 고점 = MACD선 로컬 피봇 (피봇 정의는 기존 스토캐 피봇 로직 재사용). MACD 파동은 T3 파괴 판정에서 대파동 범주로 취급.
- GC = 해당 두 MA의 봉 마감 기준 교차 (as-of 규율 동일).

## 3. 캠페인 레이어와의 결합 (v3 구조)

- 추세 레이어는 TF별로 독립 산출되는 **배경 상태**다. 캠페인(기법 1)의 S0~S7은 불변이되, 캠페인 저널에 `trend_state`(T0~T4), `trend_state_at_entry`, `bottom_width` 컬럼이 붙는다.
- **v3 가설 (사전 기록)**: 기법 1 캠페인의 엣지는 추세 상태에 조건부다 — T1~T3 진입은 유효, T0 한복판 진입이 median 음수·저점이탈 84%의 주범. 이 가설의 채점은 v3 백테스트에서 사전 게이트와 함께 (게이트 수치는 구현 위임 시 별도 확정 — 이 문서에는 넣지 않는다).
- 게이트 승격 전까지 trend_state는 **관측 태그** — 기존 규율(관측 → 저널 분리 → 승격 판단) 동일.

## 4. 신규 구현 대상 (v3 위임 시)

1. 스토캐 4층 (40,20,20) 추가 — indicators 확장 + 패턴 검출 4층 확대
2. MA20 이평선 쌍바닥/쌍봉 검출 대상 추가 (기존 검출기의 대상 MA 확대)
3. MACD선 피봇·쌍봉(LH) 검출기
4. slope 판정기 (`TREND_SLOPE_N`) + 계단식 GC 이벤트 검출
5. 추세 상태 기계 (전이표 데이터 선언) + TF별 산출
6. S0 이벤트 `bottom_width` 계측 (폭↔60MA 턴 성공률 상관은 저널 관측)
7. 이격도(캔들-60MA) 계열은 기존 [F8] 구현 재사용 — 2파 국면 주석용

## 2.5 전조 채널 디스패처 (2026-07-08 추가 — 김박사 확정)

60MA 하락 전환의 전조도 상승과 대칭으로 급3 쌍봉이되, **어느 계기에서 전조를 읽을지는 배열 상태에 조건부**다:

| 배열 상태 | 전조 채널 | 근거 |
|---|---|---|
| 정배열 (10MA > 20MA > 60MA, 120MA) | **이평선 10MA 쌍봉** | 이평선이 살아 움직이는 국면 — 힘이 센 계기가 실제로 형성됨 |
| 비정배열 (120MA > 60MA) | **대파동 스토캐 쌍봉** | 10MA가 눌린 국면 — 이평선 쌍봉은 형성이 어렵거나 늦으므로 빠른 계기를 읽음 |

원리: 가장 힘센 계기가 아니라 **그 국면에서 실제로 말을 하는 계기**를 읽는다. 관측 도구 반영: 시그널 카드·계기판이 현재 배열 상태를 판정해 해당 채널의 패턴(candidate 포함)을 "전조" 슬롯에 표시한다 (판정·게이트 아님 — 표시 규칙).
