# 시간·봉 마감·캐시 계약

## 시간과 상태

| 항목 | 앱 | 푸시 |
|---|---|---|
| 계산·기록 시각 | naive UTC, 원본 봉 open_time | 동일, 이력 직렬화는 UTC 문자열 |
| 사용자 표시 | 마지막 단계에서 KST +9시간 | 메시지·요약에서 KST +9시간 |
| 마지막 봉 | 진행 중 봉 포함 가능 | open_time + 간격이 현재 UTC를 넘으면 제외 |
| 2d 합성 | 조회 창의 첫 원본 봉 기준 합성 | epoch 일수 배수로 시작점을 정렬하고 완성된 1d 두 봉만 사용 |
| 수신 실패 | 저장본 표시와 stale 안내 | 저장본의 마지막 봉 확정을 보장할 수 없어 해당 셀 발송 제외 |
| 후보 시각 | 확정봉과 가용 시점이 다를 수 있음 | 가용 시점 이전 발송 방지 |
| MACD | 교차 다음 봉에서도 부호 유지 시 표시 | 기본 발송 대상 아님; legacy 선택 시 적용 |

`known_pos = max(확정봉, 두 번째 극점 + 피봇 지연)`을 원본 추출 규칙대로 유지합니다. 60MA 관찰 창은 가용 시점부터 20봉이며 화면 경과는 확정봉 기준입니다. 창 길이·이벤트 시각·이미 상방/하방 제외 규칙을 이번 구조 정리에서 바꾸지 않습니다.

2d 창 기준 차이는 문서화하고 보존합니다. 통일하려면 기존 기록·이벤트 키에 미치는 영향까지 별도 검토해야 합니다.

## MTF 설명 카드의 마감 기준

기준 TF 레이더와 현재 차트의 설명은 `display/mtf_guidance_model.py`의 별도 표시 계약을 사용합니다. 원본 OHLCV에서 `open_time + 봉 기간 <= 현재 UTC`인 행을 먼저 선택한 다음 MA·스토캐스틱을 다시 계산합니다. 진행 중인 봉으로 피봇이 확정된 흔적을 남기지 않기 위한 순서입니다. 월봉은 30일 고정값 대신 달력의 다음 달을 사용합니다.

마감 전 수신한 마지막 원본 봉이 캐시에 남아 있으면 현재 시각만으로 최종값 수신을 보장할 수 없습니다. 표시 계층은 보수적으로 마지막 원본 행을 제외하고, 후속 봉을 수신한 구간까지만 설명에 사용합니다. 캐시된 마지막 봉이 시계가 마감을 지났다는 이유만으로 확정값으로 승격되지 않습니다. 후속 봉이 아직 없어 설명이 지연되면 새로고침을 안내합니다.

네이티브 TF와 UTC 왼쪽 라벨인 3h를 지원합니다. 기존 오른쪽 라벨 합성 2d·4d·2w는 시작·마감 계약이 달라 설명을 보류합니다. 원래 차트·알람은 계속 사용할 수 있으며 보류 사유를 카드에 표시합니다. 원본 신호·추적·푸시 정의는 변경하지 않습니다.

MA60 현재 방향에는 연속 유효 종가 61봉이, 다음 봉 비교값에는 60봉이 필요합니다. 마지막 마감봉을 t라 하면 현재 방향은 `C_t - C_(t-60)`, 다음 봉 비교값은 `C_(t-59)`입니다. 마감 프레임에서는 각각 `close.iloc[-61]`, `close.iloc[-60]`을 비교에 사용합니다. 값이 같으면 수학적으로 평탄이며, 기존 추적기의 엄격한 부등식·부동소수 연산에 따른 상태와 구분합니다.

누락·결측·마감 갱신 지연이 있으면 해당 확인 조건을 보류합니다. 다음 예상 마감이 이미 지났으면 과거 비교값을 미래 조건처럼 제시하지 않고 새로고침을 안내합니다. 수신 실패 저장본은 별도 상태로 표시합니다. 시각 표시는 KST입니다.

설명용 지표·후보는 기존 화면 캐시를 공유합니다. 설명 대상은 레이더의 선정 TF이며 사이드바 차트 TF와 독립적입니다. 종목별 마지막 조회 view를 세션에 저장하고 차트에서는 수신 상태나 변화 기록을 재계산하지 않고 표시합니다. 따라서 차트 TF 변경은 추가 전체 TF 조회나 관찰 대상 재선정을 일으키지 않습니다. 레이더 미조회·관찰 대상 없음·자료 부족을 구분하며, 새 조회에서 대상이 없으면 이전 view를 제거합니다.

저장 view의 조회 시각은 실제 수신 시각과 구분해 표시합니다. 모델은 `next_check_at`을 별도 UTC 값으로 반환하며, 차트에서 이 시각이 지났으면 다음 확인·잔여 기간을 재조회 안내로 바꿉니다. 과거 비교 종가를 다음 미래 봉의 조건처럼 표시하지 않습니다. **레이더 다시 조회**는 OHLCV 캐시를 비우고 알람 탭으로 이동합니다. 세션 데이터는 표시용이며 외부 푸시 이력·중복 방지 파일에는 기록하지 않습니다.

## 에너지 관측과 4일봉

`display/energy_frames.py`는 파동 에너지 관측에 한해 4d를 지원합니다. 기존 60MA 설명 카드의 2d·4d·2w 보류 계약과 구분합니다. 일봉 원본은 4d 차트와 동일한 `get_auto_limit('4d')`·`fetch_klines(symbol, '1d', limit)` 캐시를 사용합니다. 알람 조회에서 필요한 일봉을 확보하며 차트 첫 화면에서 전체 TF를 추가 수신하지 않습니다.

기존 `4D/right/right/origin=start` 그룹을 유지하되, 원본 일봉 마지막 행은 최종값 확인 전까지 제외하고 완성된 연속 일봉 4개가 있는 그룹만 사용합니다. 시작·끝 부분봉과 누락·결측은 통과시키지 않습니다. 원본 조회창의 첫 시각을 집계 기준으로 보존하므로 마감 행을 자른 뒤 기준점을 다시 만들지 않습니다. 다만 기존 차트의 조회창 자체가 이동하면 그룹 위상도 달라질 수 있습니다. 고정 epoch로 차트 전체를 변경한 것은 아니며 집계 기준을 카드와 변화 안내에 표시합니다.

에너지 관측 인덱스는 그룹의 실제 첫 일봉 시작입니다. `energy_chart_labels`에는 원래 차트의 오른쪽 라벨, `energy_bar_closes`에는 마지막 일봉 시작+1일인 실제 마감 시각을 같은 행 순서로 둡니다. 예를 들어 오른쪽 라벨이 1월 5일인 1월 2~5일 그룹은 실제 1월 6일 마감입니다. 이 원본의 부분봉을 제외한 뒤 지표를 재계산합니다.

대파동 방향은 원본 K의 1봉 차분이며 K>D 여부와 다릅니다. 현재 방향 구간 시작부터 기존 소파동 폭 검출기를 재호출하여 첫 바닥이 이전 구간에 있는 패턴을 재사용하지 않습니다. 후보는 해당 마감 prefix에서만 해석하고 확정봉에 피봇 지연을 추가하지 않습니다. 대파동 반전봉까지의 소파동 확정은 선행/같은 봉을 구분합니다. 미래 구간을 포함한 검출 결과를 과거 판단에 재사용하지 않습니다.

## 큰 추세 해석 HT1

`analysis/trend_context.py`는 같은 조회 시각의 에너지 마감 프레임에서 4d MA10과 1d MA60을 읽습니다. 방향에는 각각 연속 유효 종가 11개·61개가 필요합니다. MA 값, MA 방향, 종가의 MA 위·아래 위치를 별도로 계산합니다. 기존 `wave_energy`의 일봉 MA60 5봉 변화율·횡보 밴드나 기존 신호·게이트 정의를 바꾸지 않습니다.

각 기준의 실제 마감 메타데이터와 봉 간격을 확인합니다. 4d·1d의 마지막 마감이 서로 같은 시각일 필요는 없습니다. 각자의 다음 마감이 조회 시각을 지났는데 갱신된 봉이 없을 때 지연으로 판단합니다. 불일치·평탄·자료 부족에서는 하위 방향 해석을 보류합니다.

추세를 붙인 카드의 재확인 시각은 `min(해당 TF 다음 마감, 4d 다음 마감, 1d 다음 마감)`입니다. 예를 들어 주봉 관찰 카드라도 다음 날의 일봉 추세가 먼저 만료될 수 있습니다. 저장 view는 조회 당시 추세와 함께 보관하며, 차트 재생에서 최신 전역 가격·수신 상태를 섞지 않습니다. 만료된 카드·표의 추세 해석은 재조회 안내로 바꿉니다.

snapshot은 방향·자료 상태·4d 집계 원점 변화를 기록하고 가격·조회 시각만의 변화는 제외합니다. 4d 조회창 원점 변경을 추세 변화와 혼동하지 않도록 표시합니다. 추세 맥락 계산은 이미 확보한 일봉·4일봉을 사용하며 추가 수신 경로를 만들지 않습니다.

## 캐시와 갱신 결정

| 계층 | 키·수명 | 새로고침 |
|---|---|---|
| Binance 조회 | 심볼·원본 시간봉·조회량, 600초 | 앱 버튼과 푸시 순회에서 무효화 |
| OHLCV CSV | 심볼·원본 시간봉, `data/cache` 또는 환경변수 경로 | 꼬리 갱신·과거 보충·누락 복구 |
| 데이터 가공·지표 | 입력 프레임·함수 인자 | 입력이 달라지면 재계산 |
| 상위 게이트 | 심볼·상위 시간봉, 900초 | 독립 캐시 수명 유지 |
| 화면 추적·구조 결과 | 전체 OHLC·이평·스토캐·인덱스·관찰 길이, 600초·종류별 최대 64개 | 원본 값이나 인덱스가 바뀌면 재계산; MACD·RSI 표시 선택은 같은 결과 재사용 |

이번 정리에서는 기존 OHLCV 전용 새로고침 계약을 유지하고 버튼 도움말에 **상위 게이트는 최대 15분 캐시**임을 명시합니다. 가격을 새로 받은 직후 게이트가 즉시 바뀌었다고 가정하지 않습니다. 게이트의 추가 의존 경로에도 캐시가 있으므로 일부만 비우는 방식으로 즉시 갱신을 약속하지 않습니다.

실제 수신 시각과 마지막 봉 시각은 별개입니다. 메모리 캐시 적중을 실제 수신으로 기록하지 않습니다. 저장본 대체는 stale 상태로 구별합니다.

차트·알람 탭은 선택된 탭만 실행합니다. 차트의 현재 시간봉 추적과 알람 표·기준 TF 레이더는 같은 화면 결과 캐시를 사용합니다. 실제 수신 함수는 이 캐시 바깥에서 기존처럼 실행되므로 새로고침·수신 시각·stale 안내가 생략되지 않습니다. 계산 규칙과 외부 알림 경로는 기존 순수 함수를 유지합니다.
