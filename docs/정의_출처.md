## 이동 계약

1. 고정 원본은 원래 경로와 내용으로 보존합니다. 필요한 순수 계산만 공용 모듈로 추출합니다.
2. 이동 함수의 원본 커밋·경로·함수명·AST 해시를 매니페스트에 기록합니다. 원본과 이동 함수의 AST 동일성을 확인합니다.
3. 의존성 import의 방향 변경은 함수 본문 변경과 구분합니다. 고정 상수와 합성 입력 결과도 대조합니다.
4. 기존 화면·알림의 공개 함수는 호환 import로 유지합니다. 모듈 객체 동일성 대신 공용 계산 함수·출력의 동일성을 검사합니다.
5. 규칙 변경은 별도 사유·비교 결과로 기록합니다. 해시 기대값만 덮어써 동작 변경을 숨기지 않습니다.

## 공용 계산의 입력·출력

| 계산 | 입력 | 유지할 출력 |
|---|---|---|
| 후보 추출 | UTC 인덱스, OHLC, MA10·MA60, 스토캐·MA 패턴 컬럼 | `confirm_pos/known_pos/p1/p2/pattern_low`, 방향·전환 배열 |
| 생애주기 | 후보·가격·최근 봉 수 | 20봉 창, 원 생애주기 `_lifecycle`, 이미 상방·하방의 표 상태 분리 |
| 다이버전스 | 동일 후보의 두 피봇과 가격·스토캐 값 | 확정봉 위치별 bool, 있음/없음 표시 |
| 추세 구조 | 같은 지표 프레임 | 기준 저점, HH/HL/LH/LL 연쇄, 유지·경고·훼손, 되돌림 |
| 외부 알림 | 공용 계산 결과 | 이벤트 시각·known_pos·종류·메시지·ledger 키 |
