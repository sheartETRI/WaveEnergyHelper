# SPEC_WAVE_ALIGN_GATE_FORWARD — F2-b 승격 후 전방 추적 헌장 (frozen)

작성: 2026-09-04. SPEC_WAVE_ALIGN_GATE §6 의 실행 조항.
**본 문서의 조건은 전방 데이터를 보기 전에 동결됐다. 결과를 본 뒤에는 수정하지 않는다.**

## 0. 배경

SPEC_WAVE_ALIGN_GATE 본 검정에서 F2-b 배열 게이트가 4개 기준을 모두 통과해 승격됐다
(Δ′ = 0.3469, 월 클러스터 부트스트랩 95% CI [0.1389, 0.5925], seed 20260904).
다만 그 검정은 **같은 데이터 위에서의 확인**이었고, 보조 진단은 승격 근거를 약화시키는 방향이었다:

- 에피소드별 Δ′_e > 0 비율이 6개 셀 전부 0.5 미만 (0.240 ~ 0.407)
- 연도별 Δ′ 가 6년 중 3년 음수 (2023, 2024, 2026)
- half-split 전반 +0.5858 → 후반 +0.1037 로 감쇠

이 불안정성을 해소할 방법은 out-of-sample 데이터뿐이며, 본 문서가 그 절차를 고정한다.

## 1. 추적 기간

- 시작: **2026-09-01** (본 검정 모집단의 종료 시점 직후)
- 1회 보고: **2027-03-01** (6개월)
- 대상: 승격된 TF쌍의 LTF 이벤트만 — PAIR_B(HTF 4h → LTF 1h), PAIR_C(HTF 1d → LTF 6h)

## 2. 재검토 트리거 (동결)

> 6개월 시점 1회 보고에서 전방 Δ′ 의 월 클러스터 부트스트랩 95% CI **상한이 0 미만**일 때만
> 승격 회수 논의를 연다. 부호만 음수이고 CI 가 0 을 포함하면 추적을 6개월 연장한다.

| 조건 | 결정 |
|---|---|
| CI 상한 < 0 | `RETRACT_REVIEW` — 승격 회수 논의 개시 |
| Δ′ < 0 이고 CI 가 0 을 포함 | `EXTEND` — 추적 6개월 연장 |
| 그 외 | `KEEP` — 승격 유지 |
| CI 산출 불가 (표본 부족) | `EXTEND` |

코드 고정 위치: `analysis/wave_align_gate_forward.review_decision()`.
전방 Δ′ 의 정의·부트스트랩 방식·시드는 본 검정과 동일하다
(`validation/wave_align_gate_sweep.month_cluster_bootstrap`, seed 20260904).

이 표는 전방 데이터를 보기 전에 확정됐다. 보고 시점에 기준을 고르는 일은 없다.

## 2-1. 주 지표와 쌍 구성

- 6개월 보고의 주 지표: 전방 Δ′ = 승격과 동일한 PAIR_B + PAIR_C 통합.
  쌍별 Δ′는 보조 보고이며 회수/유지 판정에 사용하지 않는다.
- 통합 CI는 산출되나 PAIR_C 셀의 게이트 이벤트가 비어 있거나 희소한 경우:
  판정은 결정표대로 통합 CI로만 내리고, PAIR_C 공백은 한계로 기재한다.
- 추적 개시 시각 = 커밋 3의 타임스탬프. 커밋 1·2는 추적 개시 전 사전 작업이다.

## 3. 무개입 원칙 (검증 가능한 형태)

1. **gate_align 은 기록 전용이다.** 어떤 필터·정렬·점수·알림에도 사용하지 않는다.
   표시 UI 는 상태를 보여줄 뿐 이벤트 집합을 바꾸지 않는다.
2. **원본 저널을 수정하지 않는다.** `wave_live_forward_journal.csv` 는 그대로 두고,
   플래그는 사이드카 `validation/wave_align_gate_forward.csv` 에만 쓴다.
3. **정의 파일을 건드리는 커밋은 추적을 무효화한다.** 대상 파일:

   | 파일 | 무엇을 고정하는가 |
   |---|---|
   | `analysis/wave_htf_gate_v2.py` | F2-b 게이트 정의 (MA60·120·240, 기울기 창 1봉) |
   | `analysis/wave_htf_gate.py` | asof 조인 규칙, 트리거(Filter_C ∪ Filter_Q) 정의 |
   | `analysis/wave_align_gate_forward.py` | 플래그 배선, 재검토 트리거 |
   | `analysis/wave_live_watchlist.py` | 이벤트 검출 |
   | `analysis/wave_live_forward_journal.py` | 이벤트 저널 |
   | `indicators/moving_averages.py` | MA 계산 |
   | `config/settings.py` | MA 기간·레이어 정의 |

4. **회귀 테스트가 3번을 강제한다.** `tests/test_align_gate_forward_integrity.py` 는
   동결 fixture 에 대해 게이트·트리거·asof 산출물의 해시 동치성을 검사한다.
   위 파일들의 의미 있는 변경은 이 테스트를 깨뜨린다. 테스트가 깨진 채로 추적을 이어가면
   그 추적은 무효이며, 기간을 처음부터 다시 세어야 한다.
5. 무개입을 깨야 할 실제 사유(버그 등)가 생기면, 고치되 **추적을 리셋하고 그 사실을 보고에 남긴다.**
   조용히 이어가지 않는다.

## 4. 범위 제한

- 이 배선의 범위: gate_align 플래그 + 회귀 테스트 + 게이트 개방/폐쇄 표시 UI.
- **자금 관리 코드는 건드리지 않는다.** 병행 연구를 하더라도 커밋 단위를 분리해,
