## 연구 질문 (김박사 가설, 데이터 확인 전 제시 — 사전 등록 자격)

과매도 매수는 승률이 높은 편이나 무조건은 아니다.
- **① C1** 완전 역배열의 과매도는 오히려 나쁘다 (회피 가설).
- **② C2** 장기 이평선(120일선) 상승 중의 과매도는 좋은 기회다.
- **③ C3** 상위 프레임(4d) MACD 골든크로스 이후의 과매도는 확률이 높다.

## A. 지표·이벤트 정의 (동결)

- **과매도 = Wilder RSI(14) ≤ 30** (김박사 확정). 신규 지표 `indicators/rsi_wilder.py`
  (`WILDER_RSI_PERIOD=14`, `OVERSOLD_THRESHOLD=30.0` 노출). 유효 구간에서 기존
  `oscillators.add_rsi`의 `rsi_raw`와 비트-동일(테스트), 워밍업은 NaN(경계 오검출 방지).
- **이벤트 = RSI가 30을 상→하 교차한 봉** (직전>30 & 현재≤30, 진입 봉만 — 연속 과매도 중복 방지).
- **대상 = BTC/ETH/BNB/SOL 일봉.** 심볼당 이벤트가 희소(전체 21~36건)하여 **4심볼을 풀링**한다
  (위임 "다중비교 억제" — 심볼별 개별 검정 대신 단일 풀 분포; n≥30 임계는 풀링을 전제로 성립).
- **forward = 익일 시가 진입 → k일 뒤 시가 청산 로그수익** (8차 `regime_forward`와 통일).
  주 창 k=20, 부가 5·60. 범위 밖(청산 봉 없음) 이벤트는 제외.
- **겹침**: 이벤트 forward 창 중복은 그대로 두고, n과 함께 **유효표본(비중복 근사)**을 병기한다
  (심볼별 시간순 그리디로 20봉 이상 간격 이벤트만 세는 근사).
- **조건군**:
  - **C0** 무조건 (베이스라인).
  - **C1** 완전 역배열: `MA10 < MA20 < MA60 < MA120` (이벤트 봉).
  - **C2** 장기 상승: `sign(MA120[t] − MA120[t−5]) > 0` (기법0 slope 정의·N=`TREND_SLOPE_N`=5).
  - **C3** 상위 TF MACD GC 국면: 4d(1d의 상위) MACD선 > 시그널선. 4d는 1d를 리샘플
    (app과 동일 파라미터: `4D`, label/closed=right, origin=start), MACD(12,26,9)를 4d 종가에
    산출 후 봉 마감(우측 라벨) 상태를 1d로 as-of ffill(선견 없음).
  - 교차 **C2∩C3** 포함(탐색 단계 조합 허용).

## 홀드아웃 설계 (탐색/확인 시간 분리 — 이 프로젝트 최초)

- **심볼별 시간 50:50 분할**: `mid = n // 2` (봉 수 기준 중앙). 전반=탐색, 후반=확인.
- **후반 데이터는 탐색 단계에서 로드 금지 (코드 수준 분리)**:
  - `explore` 실행은 `full.iloc[:mid]`만 로드해 지표·이벤트·forward를 전반 안에서 계산한다
    (전반 이벤트의 forward 창은 전반 안에서만 — split 이전 시가만 사용).
  - `confirm` 실행은 full을 로드하되(지표 워밍업 연속성) `idx ≥ mid` 이벤트만 채점하고 forward는
    후반 시가만 사용한다. 지표는 인과적(백워드)이라 전반 구간 값은 두 로드 방식에서 동일하다.
  - 코드 불변식 assert: explore 이벤트·forward는 split_ts 이전, confirm은 split_ts 이후.
- **선정과 확인 기준은 후반 개봉 전 본 리포트에 기록**(아래 선정 규칙 → §B 선정 → 커밋 → 그 후 `confirm`).

## 선정 규칙 (사전 등록 — 탐색 수치 확인 전 고정)

> 아래 규칙은 전반(탐색) 수치를 보기 **전에** 확정한다. 규칙을 데이터에 맞춰 바꾸지 않는다.

- **양(+) 가설 후보 = {C2, C3, C2∩C3}.** 이 중 전반(풀) 기준으로 **① n ≥ 30 이고 ② fwd20 mean과
  median이 모두 C0(전반)보다 높은** 군을 자격 후보로 한다.
- 자격 후보를 **fwd20 mean의 C0 대비 상승폭** 내림차순으로 정렬해 **상위 최대 2개**를 확인 대상으로 선정.
  자격 후보가 2개 미만이면 자격을 갖춘 수만큼만(0~1개) 선정한다(억지로 채우지 않음).
- **C1(역배열)은 선정과 무관하게 항상 확인 대상**(회피 가설, 별도 기준으로 후반 단발 검정).
- 선정 결과·근거·타임스탬프를 §B에 기록한 뒤에만 후반을 개봉한다.
